# MultiPan 0.71.0 多文件夹与文件混合批量移动

2026-11-17 Windows x64。按大更新交付完整的选择、目标确认、整批预检查、逐项执行、停止与结果流程。真实账号待用户验收；不把0.69/0.70回收站等尚未反馈功能记为验收通过。

## 功能
- 夸克、123、百度、光鸭、诚通WebDAV和通用WebDAV支持同一目录内多个文件夹及文件混选，一次最多50项；顶部按钮、右键菜单、拖动已选项目均使用整组。拖动未选项目仍只移动该项，不隐式包括其他选择。蓝奏文件夹移动继续禁用。
- 目标选择器列出所有源项目名称和文件夹数量，禁止选中源文件夹作为目标。ID型目录还在后端逐条核验源/目标层级，不依赖ID字符串前缀猜测子目录。
- 含文件夹的多项批次先调用只读ValidateCloudMoveBatch：全组账号/父目录/目标一致、最多50项、无重复/同名源、源ID/名称/类型唯一存在、目标无同名项目、目录不可进入自身/子目录。任意一项不通过，整批不发移动请求。
- 预检查通过后逐项调用原有单项移动API，每项仍复核来源和目标。含文件夹批次遇首项错误或结果待确认停止后续；停止按钮等待当前请求完成，未开始项不执行，成功项不回滚，不自动重试。
- 原有文件夹移动后的默认上传位置、可重试任务目录路径更新及浏览历史失效逻辑逐项沿用。账号来源变化后不继续旧批次；选择器小窗口布局已修正，源列表和目录列表滚动，底部按钮可见。

## 限制
预检查和后续移动不是服务端原子事务，其他客户端可能在两者之间改变目录；每项再查不能消除所有并发窗口。目录只确认自身移动，内部内容需用户核对。已有纯文件批量保持逐项错误后继续的旧行为，含文件夹批次遇错停止。未开始队列及最近移动结果不跨重启保存，不自动续跑；已成功项不回滚。网盘结果待确认请检查原目录和目标，勿反复提交。
夸克还原协议核对仍未取得足够证据；现有作者文档https://github.com/zhaocongqi/clouddrive-auto-save/blob/main/docs/quark_apis.md仅支持本项目已用的回收站列表及彻底删除说明，不能据此猜恢复接口。本轮按正式清单推进第4项多目录移动，不标记第3项或第4项全部完成；盘内复制及蓝奏目录移动仍待办。

## 用户复测
1. 退出旧版运行0.71.0，在一个支持的网盘准备两个可丢弃文件夹和一个文件，混选后移动到；先核对名称/数量和目标，再取消，官网应不变。
2. 再选一个空目标目录，执行移动，官网核对源移除、目标出现、目录内部内容及文件完整性；如目录曾为默认上传位置，核对配置路径。
3. 给第二项制造目标同名占用，整批预检查应拒绝，第一项也不移动。清除测试冲突后再操作。
4. 尝试把目录移入自身/子目录应拒绝；执行中停止后续，已完成项保留，未开始项不动。对待核对结果先检查两端，不重复提交。
5. 换另一支持的网盘复测，蓝奏含文件夹选择仍不能批量移动。失败反馈版本、网盘、步骤及脱敏错误，不发送凭据/state.enc。
