# MultiPan 0.84.0：可信原件夸克作为中转来源

2026-11-18，Windows x64。新增夸克文件→百度 / 123 / DAV，**仅限具备本机可信原件指纹的文件**。不支持任意夸克文件、夸克目标、目录中转或删除源搬运，第5阶段未全部完成；真实账号待验收。

## 适用条件与流程

本机通过MultiPan上传文件且成功保存原始SHA256及云端绑定后，才可能具备可信指纹。选择夸克来源并读取目录时，仅列出当前账号、文件ID、名称、大小和有效版本信息均与指纹匹配的文件；旧上传、非本机上传、重复/缺失指纹、元数据缺失或已变化的项目不列入。没有可用项目不影响普通浏览与下载。

不能把夸克JSON MD5建议值当作原件依据。排队只接受后端保存的可信SHA256，前端不能传入自选哈希；下载实际字节SHA256须匹配该指纹，响应提供Content-MD5时也检查其格式和字节一致性。不匹配不提交目标上传。

完整缓存继续时，除锁定并核对缓存外，也先完整回读当前夸克来源，再允许提交目标。目标完整回读通过后，完成前额外完整回读夸克来源SHA256，并再查元数据，不能只依赖文件ID或时间戳；即使这些字段未变，只要当前读回字节不同也保持待核对。界面显示“复核夸克来源”阶段及进度。仅证明读取时内容一致，不保证永久状态。

这会增加来源完整下载和目标回读，使用正常下载权限、额度与网络流量。额度不足、验证要求或网络异常时按正常错误处理，不绕过服务限制。来源文件保留；目标仍使用已接入百度 / 123 / DAV的保护规则。

指纹来自当前本机加密状态中的上传原件记录，不扫描用户其他文件。账号凭据/来源变更按现有规则隔离并清除旧指纹；旧任务不跨来源复用。任务自身保存可信版本及哈希依据，重启恢复仍只读检查已提交未知，不重新上传。旧0.79–0.83记录兼容，缓存仍为本机明文，保留既有容量限制。

夸克Cookie仅按既有下载器的受信域名规则发送，不传给其他盘或非受信CDN；受信接口返回的Cookie更新只用于当前请求流程。回执不保存Cookie、签名地址或下载临时节点。本轮没有接入夸克原生盘内复制，也没有使用未经确认的copy参数。
