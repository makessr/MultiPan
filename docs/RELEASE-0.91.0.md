# MultiPan 0.91.0：DAV跨账号目录复制

2026-11-18，Windows x64。第5项新增WebDAV / 诚通WebDAV之间的目录中转复制，保留层级和空目录，全部源保留。其他网盘仍只支持既有文件中转；目录跨其他盘、删除源搬运仍未完成。协议和边界见[本版审阅](PROTOCOL-REVIEW-0.91.0.md)。

## 使用和边界

在跨账号中转页选择来源和另一DAV目标，读取来源后点击“复制此目录…”，确认后先预检整棵源目录。最多8层、20个目录（含所选根）和20个文件，单文件256MiB，全部中转记录合计1GiB/1000条，预检最多45秒。超限、读取不完整、缺少大小/强ETag、重复名称或目标根同名时整批不创建。

按预检清单逐项创建目录和复制文件，之后新增源文件不追加。空目录保留；源文件不删除。目标同名目录不合并，URI路径重叠拒绝。目录先保存写前回执，再发一次创建，明确201受理保存成功并回读准确目录后才允许子项。无受理凭据的未知目录，即使已经可见，也不能仅凭同名确认；请到目标盘人工核查，不重复创建。不会自动回滚或删除，部分失败可能留下部分目标。

队列显示目录和文件各自的记录；“目录创建已核对”只说明目录创建，不代表整棵子项都完成。文件仍需原强ETag和完整SHA256核对。预检中也可停止：等当前读取返回后不再入队。停止/退出会保留部分结果，重启不自动继续；先确认父目录，再手动继续未提交的子项，已提交未知项只读核对。父目录未确认不能绕过依赖；清理须先子项后父记录，只清本机记录/缓存，云端项目保留。原中转缓存保护和来源隔离保持。

先从托盘退出旧版，勿让0.90及更早版本写同一状态文件。原透明PNG、图标备份和旧产物保留；搜索仍为根目录与两级子目录、全账号首匹配切盘。

## 醒后测试

1. 用两个可用DAV配置，在来源准备可丢弃的小目录，包含中文文件、两层子目录、空目录和空文件。复制到目标空位置；应保留层级和内容，源全部存在。检查每个文件已核对、每个目录创建已核对。
2. 再复制同名根目录，应整批拒绝，不合并/覆盖。确认窗口点取消应无目录队列或云端创建。
3. 正常小目录复制时可点停止，重开后已有记录保留。先只读核对未知父目录，再按顺序继续未提交子项；没有受理凭据应保持待核对，不重发。不要为验收故意断网或制造真实失败。
4. 完成后按子文件/子目录、父目录顺序清理本机记录；云端源和目标都应保留。父目录有子项记录时不能先清理。
5. 回归原单文件中转与123维护/恢复、限定两级目录搜索。没有两个适用DAV配置可跳过，不需要购买权限；其他盘暂不出现目录复制入口。
