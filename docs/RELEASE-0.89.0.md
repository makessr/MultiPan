## 行为

侧栏“123登录维护”只读取本机维护状态。手动更新需要先确认对应账号；取消不会发送本次更新。明确启用自动更新后，程序运行期间按分钟检查本机计划，首次下一轮后台检查尝试，以后每12小时计划一次；应用退出后不运行。该计划不是服务商有效期，未做真实12小时等待验证。

更新前读取原令牌的服务端UID，保存加密写前标记后请求更新，再用返回令牌读取UID。只有严格相同且当前账号配置未变、结果成功保存，才采用新令牌。支持大整数UID，不经浮点转换；不信任JWT自述身份。固定来源、不跟随刷新跳转、不重试刷新；不返回或记录公开Token、UID、私有来源证明及服务商原始错误，也不展示未识别的服务端expire字段。

已核验同一身份的轮换保留原来源标识和原件指纹，原未知回执/暂停任务继续受原条件约束，不会自动恢复任务。手动更换凭据建立新的来源代际并清旧指纹；再次使用曾用Token也不能重新激活旧关联。仅改名称且登录信息留空保留来源。已保存的身份与当前读取不一致时隔离旧来源、清指纹并停止自动更新，不发送刷新。

正在上传、排队/运行下载、旧直接下载、相关连接检查/搜索或其他互斥操作时不开始更新。更新过程中账号保存/移除受原互斥保护；其他账号移除导致列表重排也不会把结果保存到错误账号。

检查点保存失败不发送刷新；刷新已发送而响应、身份或最终保存不能确认时，保留写前未知标记、暂停自动更新。重启后也不自动重发，手动再次更新被阻止，需要原账号重新登录。手动重新登录仍按来源隔离规则处理旧任务，可能需要到官网核查旧来源回执。待核对中心新增登录更新记录，仅提供维护入口，不提供重放或只读刷新入口。移除账号会移除该账号的维护元数据，原文件操作回执继续按原规则保存。

账号与来源证明仍在DPAPI加密数据内。新增私有维护字段不接受前端自选；旧配置默认关闭。**升级后不要让0.88或更旧版写入同一账号数据文件**；旧程序保留归档，先从托盘退出旧版。
