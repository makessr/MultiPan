## 行为

123登录维护出现“核对已收到的令牌”时，可手动读取该候选的服务端身份。一致并保存成功才采用，自动更新保持关闭，不再次请求刷新令牌，不重试原上传、分享、删除或其他任务。收到的候选先随原UID/来源证明加密保存，再进行原二次读取；重启仍保留可核对状态。

读取失败保留候选，可稍后只读核对；结果保存失败保留原凭据与待确认候选；身份不一致则弃用候选，需要重新登录。没有收到令牌、候选保存失败或旧0.89未知记录没有候选时，只提供重新登录，不能猜测或重发刷新。待核对中心仍只提供原登录维护入口。

核对无需再次使用可能已经失效的旧令牌读取身份，原身份依据必须来自刷新前已经保存的服务端UID。配置、来源、候选均需一致，忙碌/取消/退出时不采用；当前账号按ID重新定位，其他账号删除引起重排不会写错。成功保留来源/指纹/旧回执；手动更换凭据清候选并建立新来源，仅改名称且凭据留空保持。

令牌与身份依据只在DPAPI加密状态内，前端仅见可核对标记及时间。**先从托盘退出旧版，勿让0.89及更旧版写同一状态文件。** 原透明图标和备份保留，搜索仍为根目录与两级子目录，全账号每盘首匹配后切下一盘。
