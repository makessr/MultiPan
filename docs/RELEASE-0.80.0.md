# MultiPan 0.80.0：123云盘 → DAV 文件中转

2026-11-18，Windows x64。本轮将中转来源扩展到123云盘，目标支持另一份 WebDAV / 诚通 WebDAV 账号。原0.79 DAV互相复制和旧记录兼容保留。123作为目标、其他网盘来源、目录中转及搬运删除源尚未接入，第5阶段未全部完成；真实账号待用户测试。

## 完整流程

在侧栏“跨账号中转”选择123来源、来源目录和文件，再选择DAV目标账号及目录，核对方向后创建队列。每批20文件、单文件256 MiB、保留记录总大小1 GiB/1000条、顺序处理等限制沿用0.79。

源目录须返回准确父目录、文件ID、类型、大小和32位内容MD5。缺少或矛盾即拒绝整批；大型ID始终使用字符串/json.Number，不经过浮点。排队时记录MD5，下载解析时再次绑定同一文件版本，实际下载字节同时计算MD5与SHA256；MD5不符不发送目标PUT。下载后和最终目标回读前后再检查源目录与原MD5。MD5是该服务提供的内容参照，不作为抗恶意碰撞的安全保证。

复用已有123下载解析、HTTPS/地址检查和受控跳转。API Bearer仅发往固定123 API；解析节点/CDN不携带API Cookie或Bearer。下载临时地址、签名参数和登录凭据不进入中转回执。目标沿用If-None-Match:*条件上传、完整SHA256回读和源保留；写前持久记录、未知只读不重发、停止/重启暂停、缓存归属和清理继续生效。缓存仍为本机明文文件。

重启后尚未提交的任务需手动继续；已提交未知只读核对。123登录失效按既有流程提示重新登录，不绕过验证；凭据或端点来源变化后旧记录不能复用。登录恢复不等于自动重发未知请求。
