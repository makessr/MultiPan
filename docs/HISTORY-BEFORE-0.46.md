# MultiPan

Windows 本地多网盘上传客户端，使用 Go + Wails 3 + Vue + TypeScript。当前版本：0.45.0 集中试用预览。

试用交付：`releases/MultiPan-0.45.0-windows-x64.zip`，包内只有EXE、TRIAL-GUIDE.txt和SHA256.txt。构建后可运行 `scripts/package-trial.ps1` 重新打包；脚本逐项核对压缩包内文件及SHA256，不打包账号状态。

## 复制上传任务结果（0.42.0）

每条上传任务提供“复制任务结果”，含版本、网盘类型、文件名、目标目录、状态、字节数及现有错误说明/最近尝试时间。不读取账号登录配置或本地源路径；错误说明来自原任务，对外发送前仍需检查。仅点击时写剪贴板；失败单独提示，不改变任务状态，也不重传文件。

## 上传任务筛选（0.41.0）

上传任务支持状态计数、网盘类型及文件名/目标目录搜索，条件按交集筛选。状态计数按全部任务统计，不随搜索改变；同种网盘的多个账号统一归到该类型。列表保持新任务优先，轮询刷新保留筛选，新建上传成功后清筛选显示任务。筛选不更改任务、状态或上传目标；停止/重新上传仍逐项点击。没有匹配项时可清除筛选。

## 下载结果筛选（0.40.0）

批量及文件夹下载结果支持按全部、校验通过、已保存但未验证、未完成分类，按文件名或相对路径搜索。计数基于全部已返回的结果，不受搜索影响；处理中结果持续更新。筛选只改变显示，重试仍只处理完整清单的未保存项，复制报告仍包含所有结果。开始新下载或切换网盘重置筛选，重试保留筛选。未验证项已保存，不计为失败。

## 下载保存位置（0.39.0）

单文件、批量和文件夹下载的已保存结果提供“打开保存文件夹”和“复制路径”；文件夹下载另可打开保存根目录。打开位置仅调用资源管理器显示目录，不运行文件。文件夹丢失、启动失败或剪贴板失败单独提示，不改变下载与校验结果。当前运行最多保留8192个下载位置，退出清空。

## 运行

双击 bin\multipan-0.45.0.exe。普通使用只需要 Windows 10/11 x64 和 Microsoft WebView2，不需要服务器、Go 或 Node.js。

1. 点击「添加网盘账号」，添加蓝奏云、夸克、123 云盘、百度、诚通、光鸭或 WebDAV 账号。
2. 选择本地文件，或从资源管理器拖入「新建上传」的上传文件区域，可一次添加多个文件。
3. 勾选目标账号，分别填写保存目录。
4. 点击「开始上传」，在传输记录查看各目标的结果。

文件从电脑直接上传到所选网盘。本程序不提供第三方中转服务器，不自动删除本地源文件。

## 文件拖放（0.14.0）

在「新建上传」页，从 Windows 资源管理器将一个或多个文件拖入上传文件区域，松开后加入待上传列表；列表已有文件时也可继续拖入。同一路径的重复文件会忽略，文件夹及无法访问的项目会提示跳过。拖入不自动上传，选择目标网盘后仍需点击「开始上传」。暂不支持拖入本地文件夹；云端文件拖动见下节。

使用 Wails 原生文件拖放获取本地路径。文件元数据筛选测试及生产构建通过；隔离窗口已检查显示。当前自动化接口限制跨窗口鼠标拖动，资源管理器到程序的实际拖入手势仍待用户实测。

## 目录导航与会话位置记忆（0.38.0）

路径栏新增后退/前进，快捷键Alt+←/Alt+→；Alt+↑仍返回父目录。各网盘独立记住本次运行的最后成功目录，切换回来会重新读取该位置。每个账号/来源最多50个成功位置，不缓存文件列表、不保存凭据、不写磁盘，退出后清空。

刷新当前目录不重复入历史，也不丢失前进分支；后退后访问新目录会替换前进分支。只有读取成功且响应仍属于当前请求/账号来源时才记录或移动指针，失败保持原历史并提示重选。账号类型/地址/用户名改变时不沿用旧来源路径，移除账号会清相应记忆。已知文件夹重命名或目录移动后重建当前账号历史，避免沿用旧路径。外部删除/变更导致历史位置失效时可从根目录重新进入，不自动修改或重建云端目录。

旧下载结果/来源与未完成重试仍按既有规则保留；正在下载、读取、修改或弹窗中不可通过历史导航打断任务。此功能仅当前运行的位置记忆，不是跨重启恢复或下载后台队列。

## 文件列表筛选与排序（0.37.0）

新增“全部 / 文件 / 文件夹”显示筛选，可与当前目录名称搜索叠加。排序下拉支持名称、大小、类型升降序，点击相应表头也可切换。文件夹始终优先；按大小或类型时文件夹按名称升序，文件同值时也用名称自然排序。未知大小始终放在普通文件末尾，空文件0字节不是未知。蓝奏显示大小仅为近似排序参考，不进入上传/下载校验。

类型列按扩展名显示如PDF文件/ZIP文件，无扩展名仍为文件。筛选无匹配时明确提示并提供清除筛选；底部显示当前目录总数与过滤后数量。切换名称/类型筛选会清选择、拖动及右键状态，避免操作隐藏项目；排序按ID保留选择。Ctrl+A仅选择当前可见普通文件，不会选择隐藏项目或文件夹。只处理本次已读取列表，不递归搜索、不改云端元数据，不改原下载清单、校验或重试来源。

## 文件管理快捷键（0.36.0）

Ctrl+A全选当前显示普通文件、F2重命名单个选中文件、Ctrl+Shift+N新建文件夹、F5刷新、Alt+↑返回上级、Shift+F10打开所选文件/多选组右键菜单（无选择则目录菜单）、Esc取消选择。新建与重命名仅打开既有弹窗，确认才提交。输入框/文本编辑/中文IME组合态/弹窗/其他页面不触发；传输或读取中阻止相应命令。受控F5保留下载结果，不新增删除或自动下载快捷键。F2暂只支持单个普通文件；文件夹仍用行内或右键重命名。

## 右键菜单统一提供新建文件夹（0.35.2）

文件、文件夹和多选文件的右键菜单也提供“新建文件夹”，与空白处入口一致，统一在当前浏览目录创建。仍复用现有新建弹窗与校验；文件夹右键菜单随项数增加调整边缘定位。

## 常用文件操作直接显示（0.35.1）

根据用户反馈，移除文件行的三点菜单，下载、重命名、移动改为始终可见的文字按钮。调整操作列宽度，窄窗口也不隐藏文字。网盘暂不支持的文件夹移动显示禁用并说明原因，不会发不支持的请求。同时增加文件/文件夹右键菜单、多选右键批量操作，以及列表空白处上传/新建/刷新/全选菜单。支持键盘方向键、Escape和点击外部关闭。其他UI和后端协议保持。

## 文件管理器界面与操作流程（0.35.0）

默认进入文件管理。左侧直接选择网盘，支持同类型多账号按序号区分；文件页不再重复放网盘下拉框。当前目录的上传、新建与刷新集中在顶部；全选放在表头，点击文件行可单选，Ctrl/Shift可多选/连选。选中后显示下载/移动操作，行内保留下载，重命名和移动放在更多菜单。新建、重命名、本地上传确认改为弹窗，目录默认设置降为次要操作，不再把“设为上传位置”作为主按钮。

“上传文件”只传当前目录；“多网盘上传”是独立的选文件/选目标流程，宽窗口并排显示。目录选择只更新本次草稿，不写默认目录；账号设置的目录选择也仅更新表单，保存账号时才提交。默认目录仍可从文件页目录设置明确修改。刷新账号快照只更新仍跟随默认值的目标，不覆盖已选草稿。

上传任务与下载结果分开。CloudFiles保留挂载，切到上传任务或多网盘上传不会丢下载结果；同账号刷新/浏览目录也保留最近一次结果、原始来源与重试清单。在其他目录查看结果仍可按原来源重试。复制报告使用原下载来源，避免误标当前浏览路径。切换账号、开始新下载或退出仍会更新/清除当前结果，不是持久下载历史或后台队列。正在下载时可在文件与下载结果间切换，但仍限制切账号和其他云端变更。

视觉采用浅灰导航/白色工作区、紧凑文件表格、蓝色行动与选择、文件夹金色识别。支持弹窗Tab循环、Escape取消、更多菜单避开列表裁切。预览工具tools/ui-preview使用独立Vite配置与纯模拟API，不读取账号、凭据、本机文件，不操作云端；正式构建仍使用真实Wails绑定，不包含演示API。

试用重点：侧栏切网盘和返回上级；文件选择与更多菜单；本次上传目录不改变默认；新建/重命名弹窗；多网盘上传与任务；下载后切页面/目录再查看和重试。已有协议、校验、无覆盖及拖放移动语义保持；云端拖放仍直接移动，不增加确认。

## 下载速度和预计剩余时间（0.34.0）

单文件、批量、文件夹及未完成项重试的进度区新增近期平均下载速度和当前文件预计剩余时间。批量/文件夹以当前文件计算，不把它冒充整个目录总耗时；切换文件或开始新尝试重新采样。未知大小不猜剩余秒数，样本不足显示等待采样；3秒无新数据显示暂无新数据，恢复后重新更新。内容接收完成显示正在校验并保存，不把校验/刷盘等待当作网络卡死，也不提前称校验通过。

估算使用单调时钟、近期字节样本及500ms刷新；不改变传输协议、校验、取消、重试或本机无覆盖规则。自动时钟测试覆盖正常/长流/停顿/恢复/切文件/重新开始/未知及零大小/无效样本/元数据等待/时钟回退；组件验证进度流隔离、文件切换和重试重置。真实显示待试用，0.33.0文件夹重试尚未得到用户验收。

## 文件夹未完成项重试（0.33.0）

文件夹下载结果中新增「重试未完成」。首次扫描及本地目录创建完成后，失败、取消和未执行文件可继续下载到原保存位置；所有已保存项（包括未验证项）不再请求，结果及校验详情保留。不弹保存目录选择框、不重新扫描整棵树，不自动纳入后来新增的云端文件，每个未完成文件仍沿用单文件的来源核对/长度/摘要与无覆盖保存。

重试仅接受后端生成的不透明记录ID及原账号/来源，文件清单、路径和状态从后端内存取；核对账号来源和原创建目录的Windows身份，目录删除/替换时停止，不把已有目录当作可合并目录。同名文件继续拒绝覆盖，其他未完成文件可以继续。重复点击与其他下载互斥，取消保留已保存项，重试错误不清空结果。

记录限本次运行最新一次目录下载；页面刷新/离开后不再提供重试入口，重启不恢复。扫描或本地目录创建期间取消、尚未形成完整文件清单时不提供此入口。新建完整目录下载仍须新根目录；本功能不是断点续传或任意目录合并。用户已确认0.32.1蓝奏多层目录文件保存成功，缺可信摘要保持未验证。

## 蓝奏下载兼容修复（0.32.1）

修正现代蓝奏分享页固定选择domain2的问题：优先采用页面公布的domain1；旧页面只有domain2时仍兼容。仅在明确DNS失败且请求未取消时，允许切换一次到页面声明、固定官方域名、相同查询参数的备用解析地址。超时、业务失败和验证响应不重放；公开解析不携带账号Cookie。网络错误单独显示，不再统称页面变化。

## 上传原件摘要与下载校验（0.24.0）

### WebDAV

填写网盘提供的 HTTPS WebDAV 地址、用户名、应用密码，保存目录填写相对该地址的目录，如 /备份。子目录会按需创建；同名文件使用 If-None-Match 条件拒绝覆盖（要求服务端遵守 HTTP 条件请求）。

WebDAV 是连接网盘的一种接口，使用此客户端不要求自己搭建服务器。具体网盘是否提供 WebDAV 以及是否需要订阅，以服务商为准。

## 任务与本机数据

- 同一文件为每个目标创建独立任务，最多同时运行三个目标账号，每账号同时运行一个任务。
- 一个目标失败不影响其他目标；失败或停止的任务可重新上传。
- 关闭程序会停止上传，重新启动后未完成任务显示已停止，不自动发送文件。
- **重新上传从文件开头开始，尚未实现分片续传。** 网络中断或停止时远端可能已有文件，请先检查再重试。
- 上传进度表示已从磁盘读取并交给 HTTP 上传的数据量；只有服务端明确确认后才显示完成。
- 账号、凭据、任务记录保存在 %APPDATA%\MultiPan\state.enc，使用 Windows DPAPI 加密，绑定当前 Windows 用户。
- 程序只允许同一 Windows 会话中的本用户运行一份；启动前锁定数据文件，避免覆盖。
- 若加密数据损坏或换用户无法解密，会提示错误并保留文件，不自动清空。
