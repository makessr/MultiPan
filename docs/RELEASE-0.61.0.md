## 用户测试（只用可丢弃测试分享）

1. 分享记录→云端分享，选123或百度普通测试分享→撤销→取消。预期原链接仍有效，无新增撤销回执。
2. 再撤销并确认。预期显示原撤销回执，官网原链接失效，网盘原文件保留；本机旧创建记录不能复制该链接。
3. 如自然遇到待确认，退出重开应保留回执。点检查原撤销结果应只核对原操作，不重发；超出500项或网络失败不可当作成功，可官网核对。
4. 清理已确认回执并重启，旧创建记录仍不恢复复制/检查能力；未知记录不能清理。其他分享不受影响。
5. 旧夸克回执仍能查看，账号来源更新后旧回执停止检查，原列表和读取功能正常。无需为了测试故意破坏网络或删除正式账号。

撤销不能恢复原链接，请勿用正式分享测试。失败提供版本、网盘、步骤和脱敏错误；不要发送Cookie、Token、加密状态或敏感分享链接。
