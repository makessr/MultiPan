# MultiPan 0.98.0

新增跨账号中转的**DAV独立文件完成搬运**。默认复制仍保留源文件；已核对的DAV/诚通DAV独立文件任务出现“完成搬运并删除源文件…”，经独立确认后重新核对两端和缓存，再条件删除来源文件。

## 范围与行为

- 来源仅DAV/诚通DAV；目标沿用百度、123、DAV/诚通DAV。仅单独选择复制的文件，不支持目录中转批次及其子项，也不支持123/百度/夸克/光鸭来源删源。本版不是所有提供商搬运均已完成。
- 显示任务原网盘类型/账号、准确来源路径、目标位置、文件名和大小；输入“删除源文件”并勾选不可还原确认。WebDAV删除可能直接永久删除，不保证服务商回收站。取消不开始。
- 重新检查并锁定完整自有缓存；完整回读目标、完整读取源，源SHA256/原强ETag必须匹配；长源读取前后均严格检查原位置的类型/大小/版本。不完整缓存、来源或目标变化、读取/保存失败时不提交删除。
- 删除前加密保存检查点，只一次DELETE携带原If-Match。仅200/204明确受理保存，且严格父列表原位置缺失、原GET返回404、目标内容再次完整匹配，才显示“搬运已核对”。
- 202异步、412条件失败、回执丢失、原位置出现新项目、读/保存失败等保持待核对。不能因源消失单独确认；无已保存受理仍未知，不重发、不清记录或原缓存。
- 停止全部中转或退出会取消正在处理的搬运。未提交的源删除不自动继续；已提交未知重启后只能只读核对。待核对中心保留中转入口，按搬运开始时间排序，不在中心发送删除或自动续跑。
- 两端不是原子事务，外部修改可能在删源后造成结果未确认。完整缓存保持，成功后也不自动清理；用户明确清理记录及缓存才删除本机副本。
- 相比已完成复制，开始搬运会额外完整读取目标两次、源一次并核对缓存，使用正常下载额度、流量和合计限速，耗时与文件大小和速度有关。仍8 GiB单文件/32 GiB保留总容量，既有工作时限和身份隔离保持。
- 新搬运状态不要用0.97及更早版打开写入；旧版不认识moving/move_unknown/moved会拒绝加载。原复制、目录、清空回收站、自选安装目录和历史网盘标签保持。

## 修改文件

- `internal/transfer/relay_move.go`：DAV独立文件资格、私有搬运回执、完整缓存锁/两端重新核对、条件删除写前/受理保存、缺失双重核对、只读恢复和未知保护。
- `internal/transfer/relay.go`：展示源路径及搬运操作资格、新状态恢复/校验/清理规则；旧复制协议不变。
- `internal/transfer/pending_review.go`：搬运处理中/未知映射至原中转入口，按本次搬运时间排序；不增加写分派。
- `relay_service.go`：开始搬运和只读检查两个异步桌面入口。
- `frontend/src/RelayPanel.vue`、`tools/check-relay-ui.mjs`：独立危险操作确认、准确来源/目标、停止/只读检查、状态标签、双击/变化/卸载守卫及原流程回归。
- `internal/transfer/relay_move_test.go`：22类完整流程、私有回执恢复及资格、两类原生目标完整读取；六处当前版本/说明、开发计划及协议报告同步。

## 用户复测

1. 若没有DAV来源，可跳过本版搬运验收，原123/百度等复制继续保留源，不会自动删源。
2. 有DAV时，只用一个可丢弃小文件，单独创建跨账号复制，等待“内容已核对”。点击“完成搬运并删除源文件…”，核对账号、来源路径和目标；先取消，源应保留。
3. 确认无误后准确输入并勾选，等待“搬运已核对”；检查源位置已无该文件，目标内容完整，本机缓存仍保留。
4. 多余场景不必制造。若出现待核对，先使用只读检查并保留缓存，不重复删除；不要故意断网测试，也不需要为验收删除其他文件。

其他七项未完成能力继续，未将开放平台说明套用到已有网页登录配置，未猜测夸克删除语义或原生复制参数。
