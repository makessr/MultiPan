# 0.92.0：123 / 百度目录作为中转来源

2026-11-18，Codex。本轮复用项目既有的123签名列表/正常下载信息和百度列表/正常下载流程，目标仅使用0.91已验证的DAV创建和条件上传。没有新增123/百度创建目录、复制、移动、删除接口，也不将DAV参数套到原生网盘。原123/百度内容MD5限制分别见0.80/0.82及后续目标审阅，目录目标和不覆盖约束见[0.91审阅](PROTOCOL-REVIEW-0.91.0.md)。

新增内部严格目录读取器，普通浏览和原单文件读取协议不变。123沿用`GET /file/list/new`、Page和每页100，要求明确InfoList、规范ID、正确ParentFileId、显式类型；采用明确Next终止或一致Total计数，拒绝缺失/null清单、重复ID/名称、提前空页/终止及总数变化。每目录最多5页/500项，异常或无法证明结束时明确“不完整”，不创建部分目录队列。

百度沿用`GET list`和每页1000，要求显式清单、准确路径/名称、规范fs_id和显式类型，拒绝重复路径/对象ID/名称。沿用原接口短页结束依据，最多读取2页，第二页仍满时拒绝为不完整；不把缺失或null清单当空目录。正常分页受服务端当时返回限制，不承诺跨页原子快照。

目录保存的私有版本字段区分DAV占位、123稳定目录ID语义及百度原始目录fs_id。百度同路径换目录ID不能沿用原清单；123按原目录ID/父ID/名称定位。每次创建目录或上传文件前、目标回读后复核捕获的祖先目录身份，文件自身仍须原ID/大小/内容版本匹配。目录ID不当作内容修订号，不以名字、大小或时间戳代替文件内容依据。

123文件仍按原内容MD5核对下载字节，百度仍要求稳定文件ID和原始内容MD5；缺少或格式异常时整棵预检拒绝，实际字节不符时停止该文件，可能留下先前创建的目标目录。文件目标完整SHA256回读和源复核保持，原件全部保留。目录清单不自动追加后来新增源文件，也不表示整个目录树的原子版本。

沿用0.91目录写前Submitted、明确201后另存CreatedAck、准确回读才放子项，未知不重发、依赖先父后子/清理先子后父、停止代次和缓存保护。来源更换仍按账号Scope隔离；私有目录依据不输出公开队列，前端不自选证明。

验证只用本机TLS合成服务和隔离配置，没有真实云端操作、权限购买或其他客户端凭据读取。真实账号分页、原MD5适用性、下载权限和GUI仍待用户验收。不要让0.91及更早版本写含原生目录标记的新状态。
