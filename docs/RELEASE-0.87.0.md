# MultiPan 0.87.0：四家云端分享批量撤销

2026-11-18，Windows x64。分享记录→云端分享新增夸克、123、百度、光鸭本页批量撤销。第2项继续推进，其他原分享设置编辑/服务商限制仍在，不标记完整分享管理全部完成。

## 操作与结果

读取一个账号的云端分享后，可逐项勾选或选择本页筛选后可撤销项，最多50项；百度100条页面也只选择前50个合格项目。翻页、刷新、筛选或切换账号会清理相应旧选择，不跨页收集。不能撤销的状态没有勾选入口。

点击“批量撤销所选”只打开全部名称清单，不发送撤销。必须勾选理解后果并准确输入“撤销分享”，再点击最终确认才逐项执行。取消不会提交。原链接将失效且不能恢复原链接，网盘原文件保留，请只用可丢弃测试分享验收。

每项复用现有单项撤销API：后端再次核对原分享、保存加密初始及写前回执、提交一次、读取原结果确认；不是原子整批，也没有整批远端事务或回滚。后项失败不会恢复前面已失效链接。第一个未提交失败、未知结果或异常即停止后续。停止按钮等待当前单项返回后停止剩余项目；不能保证立即取消已送出的请求。

逐项显示已确认/待核对/未提交/未开始。返回未知回执时可以在结果中只读检查原撤销结果；异常未拿到回执ID时，关闭后刷新本机撤销回执或到官网核对，不重复提交。已开始的同一批不能再次运行；未开始项目不跨重启恢复，需要重新选择并确认。已提交回执沿用现有加密持久化，重启从云端分享页检查，未知不清理不重发。离页或账号来源刷新会移除旧确认并阻止后续调用，迟到结果不能污染新账号页面；已送出的当前项仍需看原回执。

本轮没有新增服务商协议或桌面写方法，也不调用原文件删除接口。来源隔离、同原分享去重、回执容量、写前保存失败零提交、有限分页核对、原创建链接停用规则保持。仅使用现有四家支持的分享撤销，不包含123付费分享或蓝奏/诚通分享撤销。
