# MultiPan 0.86.0：账号连接检查与更新登录入口

2026-11-18，Windows x64。第7阶段新增集中账号连接检查：手动选择账号，顺序验证当前认证读取，显示逐项结果和尝试时间，支持停止及打开原账号的更新登录入口。自动续期协议尚未接入，第7阶段未全部完成。

## 使用方式与边界

侧栏打开“账号连接检查”，选择1至20个账号，点击“检查所选”或单项“检查此账号”。点击后才发起网盘请求；每账号最多15秒、整批最多2分钟，逐个处理，不并发轰击服务。覆盖现有蓝奏、夸克、123、百度、光鸭、诚通OpenAPI、诚通WebDAV和通用WebDAV配置，复用既有认证验证读取。DAV检查配置的默认目录，目录不存在/不可访问也可能无法确认，并不直接表示密码失效。

结果区分读取通过、未能确认、需要重查和已停止。读取通过仅代表本次认证读取可用，不表示上传/分享/删除权限或未来一直可用。网络、权限、安全验证、格式异常统一保守显示“未能确认”，不凭文本猜测过期，界面不返回提供商原始错误、临时地址或令牌。

“更新登录 / 配置”带入同一个账号；网页登录型账号打开既有官方登录流程，DAV/诚通OpenAPI打开相应编辑入口。需用户完成登录/验证并保存，再明确重查。检查不保存轮换Cookie或Token、不清理指纹、不自动重试传输、分享、撤销或删除，也不宣称自动续期完成。

停止保留已返回结果，未完成项目标为停止；离开本页请求停止，退出程序取消。结果只在本次程序内存中保留，重启需要重新检查。账号移除或来源、登录凭据、默认目录、User-Agent变化后旧结果标为需要重查；迟到响应不能恢复旧页面结果。后端单一检查会话互斥，前端重复点击、弹窗阻挡及卸载迟到请求均受保护。

## 醒后测试

1. 打开账号连接检查，分别检查一个正常网页登录账号和一个DAV账号。有认证读取权限时应显示“读取通过”和尝试时间；不应产生上传、分享或删除任务。
2. 临时断网再检查，应显示“未能确认”，已有账号仍保留，不自动称为过期。恢复网络后手动再检查。
3. 选择多个账号，中途停止或离开本页，已完成结果保留，后续项目停止；返回页面可查看当前结果，再手动开始新检查。快速双击不能启动两批。
4. 点击某行“更新登录 / 配置”，确认打开的是该账号，取消不修改原配置。需要时完成官方登录并保存，再检查；新配置不能沿用旧成功状态。实际保存仍沿用既有传输互斥和来源隔离规则。
5. 退出重开后检查结果不保留；原搜索、中转及传输记录应保持。无对应账号可跳过，不能把本页通过当作所有操作验收通过。
