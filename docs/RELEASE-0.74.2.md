2026-11-17 Windows x64。用户要求选择账号下所有网盘时，第一盘找到匹配即搜索第二盘。

选择全部账号时，每个网盘找到首个匹配后立刻停止该盘剩余项目和排队目录，进入下一盘；每盘最多保留一条匹配（文件或文件夹）。即使只有一个账号而选择全部账号，也应用首个匹配规则。单独选择一个账号时仍返回其限定范围内所有匹配。
