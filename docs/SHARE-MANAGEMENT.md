# 分享管理

文件管理负责选中文件、创建链接或读取蓝奏外链。分享记录页提供本机回执、云端分享和蓝奏目录分享。

| 网盘 | 文件管理 | 已有分享 |
| --- | --- | --- |
| 夸克 | 创建普通或合并分享，设置新链接的提取码及期限 | 分页浏览、读取链接、查看受限文件、单项或批量撤销 |
| 123 云盘 | 创建免费或付费分享。免费分享支持合并，付费分享遵循平台审核 | 免费和付费分别浏览。支持读取、撤销，以及符合条件的主题和下载设置编辑。免费分享可编辑有效期 |
| 百度网盘 | 创建普通或合并分享，设置新链接的提取码及期限 | 分页浏览、读取、编辑期限、激活冻结链接和撤销 |
| 光鸭 | 创建普通或合并分享 | 分页浏览、读取、编辑符合条件的提取码与有效期，以及撤销 |
| 蓝奏云 | 读取文件和文件夹的原外链 | 按目录读取、复制和编辑提取码，支持从本机回执定位原目录 |
| 诚通和通用 WebDAV | 使用各自的文件管理功能 | 公开分享需要服务商提供独立授权 |

## 需要新链接时

在「分享记录 → 本机操作记录」找到创建回执，点击「重新分享」。MultiPan 会打开原目录并核对原项目，全部匹配后直接打开设置窗口。合并分享沿用原项目范围，生成一条链接。确认前可调整提取码和有效期。原来设置了提取码时，窗口默认启用保护并生成新码。123 付费分享沿用原金额作为初始值，并重新确认提交审核。

原项目变更时请使用「打开原文件目录」检查。百度回执需要保存原文件 ID 才能进入重新分享。提交结果待核对时，通过新回执检查原请求。网盘返回相同链接时，窗口会明确显示。重新分享成功且新旧链接可区分时，可从新回执点击「撤销旧链接」。确认窗口同时显示要撤销和要保留的链接，提交前会核对两者。更早的重新分享回执未保存新旧关联，仍可在云端分享中处理旧链接。

旧链接撤销回执显示在新分享记录上，重新打开页面或重启后仍可查看。状态待确认时，点击「检查旧链接撤销结果」只读核对。重新分享或撤销仍依赖原回执时，清理筛选记录会保留它。本机回执中的链接和提取码是上次记录的读取结果。使用「检查原结果」可只读核对支持的回执。处理中的或待确认的操作先核对结果，再决定后续操作。

## 待确认的服务商能力

- **夸克**已有链接的提取码和期限修改需要可确认的写入接口。官方帮助列出创建时的设置项和历史分享状态筛选。[夸克使用手册](https://www.quark.cn/documents/help/file-share)
  已核对的官方 CloudDrive 技能文档只列出创建分享、分享详情、分享内搜索和已转存分享的更新列表，没有修改已有分享设置的命令，客户端内的写入请求仍需抓取确认。[夸克 CloudDrive 分享文档](https://github.com/quark-clouddrive/quarkclouddrive_offical/blob/main/skills/quarkclouddrive/references/file-share.md)
- **123 云盘**已有链接的提取码和已发布付费内容改价需要可确认的写入接口。当前网页更新请求包含主题、期限、下载权限、流量，以及适用的普通分享游客单价。[123 网页分享设置实现](https://statics.123pan.com/123pan-resources/prod/dist/src_pages_ShareList_ShareList_tsx.44c550a8f80136723960.1794308315.chunk.js)
  核对该页面脚本后，其中只有列表与设置表单的界面逻辑，提交走的公共请求模块不在该文件内，实际写入路径需在同一账号内抓取确认。
- **百度网盘**个人版已有链接的提取码修改需要可确认的写入接口。网页实现中可核对期限修改和链接激活。[百度个人版网页实现](https://nd-static.bdstatic.com/m-static/v20-main/home/js/home.ab023ea6.js)
- **蓝奏云**完整的已发布分享列表及独立撤销需要可确认的接口。现有目录入口展示文件或文件夹外链。[蓝奏帮助](https://www.lanzou.com/q/zh/wt.htm)
