# MultiPan 0.99.0：任务数据与安装占用保护

日期：2026-11-18（Asia/Shanghai）。Windows 10/11 x64 综合试用版，未签名。

本版推进系统级安装所需的运行保护，并将上一阶段的安装范围归属检查纳入当前用户安装包。**生产系统级安装尚未开放**，本版仍安装到当前用户；管理员入口、受保护机器目录权限、HKLM/公共入口和机器卸载交接仍需继续完成。

## 改变了什么

- 同一份任务数据增加 Windows 文件锁，不再只依靠会话内的 Local 互斥。旧 Local 锁继续保留，兼容旧版在同会话运行时的占用检查；程序和安装器使用同一实现。
- 程序启动后保持 EXE 只读句柄，期间不允许写入、改名或删除该文件。登录辅助窗口也受保护；不同用户、不同数据目录的多个读者可以共存。
- 安装、升级、修复或卸载在操作受管文件前取得程序目录的 Global 维护标记，持有到完成/回滚。新版程序先锁定 EXE，再检查维护标记；安装器先持有标记，再检查受管文件是否可写。正在维护时的新启动会退出并提示，已有运行句柄使安装器拒绝替换。
- 维护标记按规范化的实际目录派生，使用现存祖先句柄解析目录别名；覆盖首次创建的目录和提交过程中刚替换的新 EXE。不能读取维护状态、名字被其他内核对象占用等情况不绕过保护。
- 安装标识和登记保存 `current-user` 范围。旧缺范围仅按当前用户；不同或未知范围拒绝接管。复制载荷不能选择安装范围，提交前再次核对原归属、文件摘要、同名冲突与可写性。

`%APPDATA%/MultiPan/.multipan-profile.lock` 是零内容锁文件，退出或崩溃后由 Windows 释放锁，文件本身会保留。它不含账号信息，也不是“残留进程”证明；不要为解除占用手动删除它。锁文件非空、硬链接、目录链接/联接等异常会拒绝使用并保留原文件。程序 EXE 硬链接也不支持运行锁。

这不是对旧版跨会话行为、恶意同权限程序或机器目录权限的完整保证。不同会话/用户的内核接口已按 Windows 文档实现，本机跨进程与合成隔离检查通过；**尚未在两个真实 Windows 用户或远程桌面多会话下验收**。本版不改变账号数据位置、DPAPI 范围、中转内容校验、未知任务回执或网盘协议。

## 自动验证

- 最终定向：appguard 2.623秒、installation 8.315秒、主包2.092秒，全部通过。独立测试子进程实际持有系统句柄，文件锁专用模式刻意不创建 Local 互斥，证明文件锁本身参与排他；不把它称为真实跨用户测试。
- 正常/异常进程退出释放，另一份数据不受阻；旧 Local 锁仍阻止进入；大小写别名不能绕过文件锁；非空/硬链接/联接保留原文件且拒绝。

- 实际安装核心在已有运行句柄时拒绝升级/卸载，原程序与标识保持；准备和提交期间新程序被阻止，成功后标记释放；上一阶段scope/回滚/数据保留测试继续通过。

1. 从托盘退出旧版，安装或打开0.99.0。预期账号、目录和原任务保持，原DAV搬运记录不需要重建；不要用0.97及更早版本写已有搬运状态。
