# MultiPan 0.77.0 三家回收站永久删除

2026-11-17，Windows x64。推进计划第3项；0.75.0/0.76.0仍待用户真实账号验收，不把继续开发当作验收通过。

## 本次功能

- 百度、123、夸克回收站支持文件/文件夹单项与本页最多50项混选永久删除。选择用途区分还原和永久删除，切换清除原选择；缺原位信息不能还原的记录，如类型可靠仍可明确选择永久删除。
- 确认弹窗固定显示网盘、账号、项目名称、原位置及文件夹含内部内容。必须准确输入“永久删除”，并勾选理解不可还原，才能开始。桌面后端也校验确认文字，不能仅靠前端按钮限制。
- 先整批只读预检查，任何原记录变化、重复、已有永久删除回执或待确认还原请求都不提交本批。每项执行前再次检查原记录身份/元数据。逐项执行，首个未确认/异常停止后续；停止等待当前请求返回，已执行部分不可撤销。不自动重试写操作。
- 专用回收站接口，仅提交明确选中的原记录；不调用普通目录删除或清空接口。夸克使用record_id，123/百度数字ID不经过浮点数转换。
- 加密持久化初始记录、提交前检查点、服务端受理回执及最终状态，最多1000条。初始/写前保存失败不发送，受理/最终保存失败保留待核对，退出取消请求，重启只核对不重发。
- 只有已保存服务端受理回执且完整读取确认回收站原记录已移除，才显示“已受理并移除”。受理响应并不单独证明执行完成，记录消失也不单独证明永久删除。响应丢失或受理回执未保存时，即使以后找不到记录仍保留未知，不用存在性检查补造回执。
- 本机永久删除记录支持筛选、每页50条、单项/全部待确认只读核对、停止后续核对、清理已完成/未提交。未知不能清理。还原与永久删除的待确认请求互相拦截，避免同一记录发生相反操作。
- 修正列表不完整判定：空页但总数仍有记录、短页提前结束、分页重复或读取间总数变化，不得用来确认记录消失。列表不完整时界面明确提示并禁用操作。

## 范围和限制

每次处理明确选中的1至50项，不清空整个回收站。夸克普通目录删除的action_type歧义仍未解决，没有接入该操作。本轮接入的是独立的回收站remove协议。
永久删除无法通过回收站还原；服务商可能要求官方安全验证，程序不会绕过。状态“已受理并移除”描述协议受理及回收站记录核对，不证明底层内容已擦除，也不能排除服务商到期清理/其他客户端并发操作。云端并发窗口仍存在，不是原子事务。
准备30秒、逐项45秒、只读核对30秒；核对最多50页/5000项，超限或不完整保留未知。有保存回执的异步请求可稍后只读核对；无受理回执的未知记录不会因官网自行处理而自动变确认，需保留并在官网核查。
清理只影响本机记录，保存失败回滚；来源变化禁止核对或清理旧记录。升级后不要用旧版写入同一state.enc，防止丢失新字段。旧EXE/ZIP、未提交工作、透明图标保留，搜索规则不变。

## 用户测试

1. 仅使用确认可永久丢弃的测试文件及带子目录测试文件夹，先在官网或已有功能中放入回收站。在三家回收站选择用途“永久删除”，核对账号和项目，取消应不改变云端；确认文字错误或未勾选时不能提交。
2. 单项及混选最多50项确认后核对逐项状态和官网回收站。已受理但仍在回收站时稍后检查原结果，不重复提交。文件夹内部内容也在删除范围内。
3. 多项开始后停止，应等待当前项返回，后续不再发送；首项未知也应自动停止后续。关闭结果弹窗后列表刷新并清除原选择。
4. 退出重开，记录仍在且不自动续删。只读检查不再次删除；无受理回执仍待核对，不能清理。已完成记录可清理，云端不应再发生变化。
5. 切换账号不串记录；存在待确认还原时不能永久删除同一原记录，反向也应拦截。失败提供版本、网盘类型、逐项状态及脱敏提示，不发送Cookie、Token或state.enc。
