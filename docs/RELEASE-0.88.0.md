# MultiPan 0.88.0：待核对中心

2026-11-18，Windows x64。集中管理已有未知回执，覆盖创建分享、原分享设置、撤销分享、盘内复制、移入回收站、回收站还原、永久删除和跨账号中转8类记录。原计划中各服务商编辑/复制/目录/续期限制仍在，没有以本轮替代缺少可靠协议的功能。

## 行为与边界

打开“待核对中心”或刷新仅读取本机记录，不请求网盘。按操作、账号、名称及是否可核对筛选，每页50条。最多展示最新2000条，同时返回实际总数；超限明确提示筛选仅作用于已展示记录，更早项目需去原模块。已完成回执不会仅因后来移除账号而重新变成中心的未知记录；原本未知的旧来源/已移除账号记录仍显示，禁止复用其来源进行核对。

选择当前页最多20项后手动只读核对，或核对单项。七类同步核对分派只调用原有Check方法，不重放创建、设置、撤销、复制、删除或还原请求，不清理未知回执。每项仍经过原模块的来源、运行状态及持久回执保护。结果仍未知时保留，可继续检查其他所选项；读取失败或手动停止会停止后续。停止/离页等待当前已送出的核对返回，不自动恢复未开始的核对。

中转核对可能完整下载目标及来源，统一在原中转页操作；中心显示中转未知记录并提供入口，但新检查接口拒绝启动中转检查，不能把后台启动误作核对完成。处理中或来源失效、当前不能核对的记录保持禁用，提示到原模块或原账号官网核查。

中心仅返回操作类别、回执ID、账号ID、名称、状态、时间及是否可核对，不输出原分享链接、密码、服务商内部句柄、路径、指纹、凭据或提供商原始错误。检查结果返回通用状态说明，细节留在原模块。记录归属和核对资格复用原历史接口，最终检查方法再次验证状态；中心不另建持久任务队列。本次选择/结果日志不跨重启，原加密回执照常保留。没有记录不代表已确认所有云端操作成功。

“前往原模块”打开对应功能页；文件类优先带入仍存在的账号，其他模块仍需选择对应账号和回执，不承诺跳到某个列表行。

## 醒后测试

1. 打开中心并刷新，核对已有未知/处理中记录与原模块一致；没有记录时应显示空状态。不要为测试制造真实删除、断网写入或未知操作。
2. 有适用未知回执时，按操作/账号/名称筛选，选1–2项只读核对。仍未知项目应保留，原操作不能重新执行；已更新结果到原模块查看细节。
3. 多项核对中停止，应保留已返回结果并不再提交后续核对；重复点击不能启动两批。筛选或翻页后旧选择清空。
4. 中转记录只能前往原中转页；旧来源失效或已移除账号的未知记录应显示但不能直接核对。无需专门移除真实账号测试。
5. 测试“前往原模块”和退出重开：原加密回执保持，本次选择/结果日志不自动恢复。没有对应记录可跳过，原搜索和传输功能应保持。
