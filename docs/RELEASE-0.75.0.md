# MultiPan 0.75.0 文件与文件夹移入回收站

2026-11-17，Windows x64。用户已确认0.74.2搜索调整正常；本轮推进计划第3项百度、123删除流程，不外推其他旧功能已真实验收。

## 本次交付

- 百度、123文件/文件夹单项及最多50项混选移入回收站。文件列表、选中操作栏和右键均有入口；弹窗固定显示服务商、账号、原目录和名称，勾选明确确认后才能开始。文件夹包含内部内容。
- 整批只读预检查；重复、失效或不同来源项目不提交整批，每项执行前再次核对原ID、名称、类型、原位置和可用大小。百度目录新增objectId，确认前同路径替换不能当成原项目。百度路径API在最后检查到提交之间仍存在并发窗口，不能视作原子条件删除。
- 顺序执行；停止等待当前项返回，遇到未确认或异常停止后续；已完成项保留，不自动回滚或重试写操作。
- 初始记录和写前提交检查点加密保存，最多1000条。初始/检查点保存失败不发送删除请求；最终保存失败保留待核对。退出取消当前请求，重启不续跑删除，已提交的处理中记录转待核对。
- 只有原目录无原ID、回收站同ID/名称/类型/原位置/可用大小匹配才确认。接口成功、项目消失或读取失败不能单独证明成功。超大数字ID不经浮点数转换。
- 本机记录支持筛选、每页50条、单项/全部待确认只读核对、停止后续核对和清理已完成/未提交记录。未知保留，同来源同项目防重放，来源变化禁止核对或清理旧记录，清理保存失败回滚。

## 范围和限制

当前支持百度、123；其他网盘删除、永久删除、清空回收站未接入。原两家还原功能保留。恢复同一项目后若需再次删除，先核对并清理原已确认删除记录；还原记录沿用既有去重规则。
预检查30秒、单项45秒、只读核对30秒。原目录及回收站各最多50页/5000项，超限不声称完整；服务端异步尚未完成时稍后点击检查原结果。元数据核对不含文件夹内容哈希，回收站期限以服务商为准。百度需官方安全验证时到官网处理，不绕过验证。
未开始批次不跨重启续跑。删除默认上传目录或祖先后，本机配置不自动改指向其他位置；还原或重新选上传目录后再上传。未知记录不因到官网自行还原而自动变为确认。
升级后不要用旧版写同一state.enc，避免旧版丢弃新增字段；旧EXE/ZIP、未提交工作、透明图标保留。目录搜索保持根目录及两级子目录、全部账号命中后切换下一盘规则。

## 用户测试

1. 两家各准备可丢弃文件和带子目录的文件夹。混选两项，核对弹窗账号/目录/名称；未勾选不能提交，取消后项目不变。
2. 确认后检查逐项状态、官网回收站及软件回收站，再用已有还原功能恢复并检查内容。
3. 选多项开始后停止，当前项返回后剩余不提交；待核对也应停止后续。先检查原结果，不重复删除。
4. 退出重开记录仍在，只读检查不重发；未知不能清理，清理已确认记录不改变云端内容。切换账号不串记录。
5. 失败提供版本、网盘类型、逐项状态和脱敏提示，不发送Cookie、Token或state.enc。
