# MultiPan 0.74.0 有上限的全盘搜索

2026-11-17 Windows x64。新增全盘搜索入口，完成单账号/全部账号选择、名称/路径匹配、扫描进度、停止、部分结果提示、分页/类型筛选及打开所在目录的流程。真实账号搜索行为待用户验收，不把旧功能未反馈范围当作通过。

## 功能与范围
本轮使用现有目录读取接口，在本机逐目录扫描和匹配，不调用服务商全文索引或读取文件内容。支持已接入目录浏览的蓝奏、夸克、123、百度、光鸭、诚通WebDAV/通用WebDAV及保留的诚通OpenAPI账号；实际可读范围受账号/接口权限影响。
用户主动开始后才扫描；可选单账号或全部账号（每次最多20个）。名称不区分大小写，可同时匹配由实际目录名称构成的逻辑路径，兼容带/不带分隔空格的路径词。结果显示名称、网盘、类型与逻辑位置；每页50条，可按文件/文件夹筛选，打开所在目录会切换到正确账号及父目录，并保留实际读取到的目录层级。

## 上限与停止
同一次任务共享2分钟、500个目录、5000个项目、1000条匹配上限，不是每个账号分别拥有上限。超过20层的目录跳过；循环/重复目录、非法或越界路径及读取失败明确显示未完整原因（最多20条）。目录计数是尝试访问数量，可能包含失败目录。
完整结束/部分结果/达到上限/主动停止/来源失效分别显示；已扫描部分没有匹配不等于整个网盘无文件。停止保留当前页面已找到的部分，离开搜索页会请求取消，结果不写入持久状态；重新进入需重新搜索。单个目录的内部分页仍沿用旧接口，不声称固定最多请求次数，网络请求受任务上下文取消/超时限制。
同一时间最多一个搜索任务，旧任务ID取消不影响新任务；账号来源变化清空旧结果，重复/迟到响应不覆盖新状态。退出程序取消查询；扫描过程中目录可能由其他客户端改变，结果不是原子快照。打开所在目录会重新读取，位置变化/登录失效按原文件浏览错误反馈，不自动下载、复制或移动。

## 用户复测
1. 退出旧版运行0.74.0，侧栏全盘搜索，先选一个网盘，输入已知文件名片段。核对名称和目录，搜索结果打开所在目录应进入正确账号和父目录。
2. 选择全部已接入账号搜索同一词，查看网盘标签。开启同时匹配路径后用已知子目录名或路径片段搜索，文件/文件夹筛选应只影响结果显示。
3. 扫描中停止，显示已停止及已扫描部分，不能显示完整无匹配。重新搜索期间不能重复启动；离开页面应停止旧扫描。
4. 大目录或读取受限时应明确部分/超限及原因，不误报全盘无结果。目录被官网移动/删除后打开所在目录应清晰报告变化，不能操作错误位置。
5. 与复制记录/移动等旧流程回归，反馈版本、网盘、搜索模式和脱敏错误，不发送凭据或state.enc。搜索会读目录，文件内容不被读取。
