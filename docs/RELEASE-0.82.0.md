## 使用与适用条件

在“跨账号中转”选择百度来源账号和目录、文件，再选择另一份123/DAV目标及目录，核对方向后创建队列。沿用每批20文件、单文件256 MiB、保留记录合计1 GiB/1000条限制。

**仅支持能核验原始内容MD5的百度文件。** 来源必须返回可靠的文件ID（fs_id）、名称、路径、类型、大小和32位MD5；排队后将文件ID与MD5共同绑定原件。缺失、非规范ID、矛盾名称或不可识别MD5整批拒绝。某些来源返回的MD5可能不是实际内容MD5；本版不解码、不猜测其含义，实际字节MD5不符就拒绝目标上传，不提供关闭校验的选项。不能把“普通下载可用”当作“本功能一定支持”。

下载解析时再核对原文件ID/MD5，流式计算实际MD5与SHA256，MD5匹配才准备目标上传。上传前及完整目标回读前后继续检查原文件ID/MD5；同路径替换成另一文件ID也拒绝。目标完整实际SHA256回读通过才确认，源文件保留。MD5是内容参照，不作为抵御恶意碰撞的安全保证。

复用既有正常百度下载入口、权限错误处理、受控跳转和Cookie域名隔离；不绕过登录验证、下载权限或配额，不接入外部解析服务。Cookie只发既有受信百度/百度PCS地址，跳转到其他域名或仿冒后缀时不携带登录Cookie；不会传给DAV或123目标。临时下载地址、签名和Cookie不进入中转回执。

继续沿用写前加密记录、未知只读不重发、停止/重启暂停、账号来源隔离、缓存锁定与归属清理。来源新增类型记录可持久恢复，旧0.79–0.81记录兼容。123目标并发仍可能留改名/未完成项目，不自动删除。缓存为本机明文；源下载及目标回读会使用正常流量和可用额度。
