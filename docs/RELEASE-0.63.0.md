## 用户测试清单

1. 先退出旧版，运行0.63.0。打开夸克的测试目录，顶部批量分享，选两个可公开的测试文件和一个测试文件夹。默认应为无码、永久，点击前官网不新增；点击后逐项得到链接，每条应只对应所选项目，文件夹内容范围正确。
2. 分别在123、百度、光鸭用少量测试项目重复。百度自动生成4位码、永久，复制链接默认填码；123/光鸭默认无码永久。用浏览器打开复制结果，核对文件与提取码。不要公开私密文件或把真实链接发到故障报告中。
3. 蓝奏选择已有分享的测试文件和目录，批量读取后应得到现有链接，官网提取码和期限不变。未能确认的项目应停止后续并显示待确认，不重复创建。
4. 用数个测试项目开始后立即“停止后续项目”。当前项可完成，其后保持未开始；点击继续才处理剩余项，已经取得结果不重新提交。正常请求很快时可能整批已结束，改用更多测试项目观察即可，不需人为破坏账号状态。
5. 若自然出现待确认：检查原结果，后续不应自动开始；确认后明确点击继续。关闭再打开、改设置也不应绕过同一待确认目标的保护。不需要为测试主动断网制造不确定操作。
6. 复制全部结果只含已取得项。关闭再重启，分享记录应保留已提交回执；未开始项不会自动创建分享。单项分享、文件选择后的下载/移动、账号切换及旧分享列表/撤销应保持可用。

失败时提供版本、网盘类型、所选类型和数量、操作步骤、逐项状态及脱敏错误截图即可；无需Cookie、Token、state.enc或真实分享链接。
