# MultiPan 0.63.2 可见分享链接与百度实际码核对

日期：2026-11-17，Windows x64。针对用户反馈修正；0.63.1基本合并分享获“测试正常”，但不能视为百度重复分享及全部组合已验收。本版真实账号待用户复测。

## 问题与修改

1. 批量分享此前只提供复制按钮，结果列表没有输出链接输入框。现已在每条ready结果下直接显示可选中的只读链接和实际提取码；点输入框可全选。百度/光鸭自动填码开关同时影响可见链接和复制结果。未知/失败项仍不展示可用链接。
2. 截图的SHARE-BD/password来自“原记录缺码或码与申请不一致”的合并判断，不能只凭截图区分两种服务端情况。弹窗每次新生成请求码，旧逻辑硬性比较请求码与原分享当前码，无法处理有效原分享使用另一实际码的响应。
3. 现只在精确原分享ID、完整所选fs_id集合、未过期状态均核对通过后读取原详情。实际码须为4位字母数字；若与申请不同，还必须有明确密码访问模式证据，显示实际码并说明差异。不会改码、重建或撤销原分享，保存的申请身份不变，去重与未知防重放继续有效。
4. 创建响应未返回pwd或pwd与申请不同，不再把申请码当成已确认实际码，继续只读核对原记录。创建响应明确返回匹配的码与合法链接时保留既有直接返回。原列表和详情都返回链接但彼此不同则拒绝。
5. 缺失、掩码、格式异常或密码模式无法确认仍保持待确认，错误分为password-missing、password-format、password-mode；不暴露原始响应或登录信息。

尚未用用户真实账号取证，无法断言本次百度后台究竟复用了链接、调整了码，还是未返回码。修正覆盖可核验实际码的兼容分支，而不是忽略核对直接标记成功。

## 自动检查与界面证据

合成HTTP测试包含创建返回不同码、创建省略码而详情返回不同码、原记录不同有效码、精确组成员核对、缺码/掩码/未确认密码模式/链接冲突拒绝；全部核对只读、不再增加创建请求，申请密码不被实际密码覆写。既有百度单项、组分享及其他分享回归保留。

实际Vue脚本验证结果链接取值，未知结果无链接；既有批量合并/分别/停止/检查/选择等脚本回归。IAB纯模拟：百度选文件与文件夹→合并分享→直接出现带提取码的只读输入框和码，无需点击复制。截图releases/ui-0.63.2/visible-share-link.png；无真实云端或剪贴板操作，预览已停。

## 用户复测

1. 先退出旧版，运行0.63.2。到“分享记录”找到原来那条百度待确认分享，点击“检查原操作结果”。无需再次创建。若能核对原分享及实际码，应直接显示可用结果；无法核对时应显示更具体的待确认原因。
2. 少量可公开测试文件和测试文件夹合并分享，成功后应直接看到链接和提取码。打开链接核对内容范围；实际码与申请不同会有明确提示，复制与可见内容应一致。
3. 按原复现步骤二次选择3个测试文件和另外1个测试文件夹合并。核对只有一个链接，全部所选内容正确；已有链接或密码不被程序自动修改。不要通过重复点击创建来解决待确认。
4. 123及其他网盘成功结果也应直接显示链接；百度/光鸭切换自动填码应同步改变可见链接和复制内容。旧暂停/继续和重启记录行为保持。

失败反馈仅需版本、网盘、首次或二次分享、项目数量/类型及脱敏错误截图；无需Cookie、Token、状态文件或真实分享链接。
