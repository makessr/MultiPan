# MultiPan 0.93.1：中转账号显示所属网盘

2026-11-18，Windows x64。修复用户截图所示问题：跨账号中转来源与目标下拉框原本只显示账号名称，无法直观看出对应网盘。

现在显示“网盘类型 · 账号名称”，例如“百度网盘 · 工作账号”“123 云盘 · 备份账号”“诚通 WebDAV · 资料账号”。同一网盘同名账号增加本机列表序号；来源/目标位置、文件复制摘要、目录复制确认都显示相同标识，目录选择弹窗保留网盘类型并带入同名序号。长名称悬停可查看完整标识，小窗口中账号栏可缩小。

这是显示修复，不重命名已存账号、不修改账号ID、来源证明、传输或持久状态格式。中转记录中的历史名称保留原快照，不依据账号后来改动的类型去猜历史网盘。原0.93目录能力与限制保持，见[0.93说明](RELEASE-0.93.0.md)。先从托盘退出旧版，再运行本版。

## 修改文件

- `frontend/src/RelayPanel.vue`：网盘类型/账号显示、同名序号、两端位置与确认摘要、目录选择传参和长名称布局。
- `tools/check-relay-ui.mjs`：实际组件增加不同网盘同名、同网盘同名、原账号ID保持的回归。
- 六处当前版本/说明：`frontend/src/version.ts`、`build/config.yml`、`build/windows/info.json`、`scripts/build.ps1`、`README.md`、`TRIAL-GUIDE.txt`；开发计划与本说明。后端业务代码未改。

## 复测

1. 打开跨账号中转，展开来源和目标，应能直接看到网盘类型与账号名。
2. 选中两端后，来源/保存位置和复制摘要应显示相同账号；如有同网盘同名账号，应出现不同序号。
3. 打开来源或目标目录选择，核对弹窗账号与所属网盘；可直接取消，不必实际提交传输。

清空回收站等正式剩余项继续推进，本版未新增回收站删除操作。反馈版本、显示缩放和脱敏界面即可，不发凭据。
