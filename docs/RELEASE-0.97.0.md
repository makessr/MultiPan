# MultiPan 0.97.0

本版修复用户截图中“中转队列与记录”只有账号名、同名时无法辨识网盘的问题，并完成当前用户安装自选目录。

## 中转记录网盘类型

来源与目标显示“123 云盘 · 保存的账号名 → 百度网盘 · 保存的账号名”，继续显示目标位置和大小，长内容有完整提示。类型来自加密任务原有SourceKind/TargetKind，名称仍用任务名称快照，不猜当前配置。账号后来改名、改类型或移除，不会把旧记录标成后来网盘。

最早未保存细分类别的旧DAV记录显示“历史 DAV”；缺少可识别类型明确显示“类型未记录”。不修改账号、上传/下载协议、文件内容、缓存、回执状态或云端数据，已有任务不用重传。公开RelayJob增加两项展示元数据，不公开私有Scope或目录证明，不增加桌面方法。

## 当前用户自选安装目录

- 首次安装可选默认目录，或在Windows目录选择器中选择父目录，程序放入其中的MultiPan子目录；取消不安装，实际目标在执行前再次显示确认。也可通过`--install-dir`传入最终绝对目录，生产安装仍需交互确认。
- 升级/修复读取当前用户已登记位置并验证安装标识，沿用原位置。已有其他位置安装时拒绝改到新目录，不静默迁移。要改变位置，先卸载原程序（账号和任务保留），再选择新目录安装。
- 已安装卸载器绑定自身安装标识及原目录，和登记位置矛盾时拒绝。临时卸载辅助进程显式传递原目录；不能落回默认目录卸载另一份安装。
- 路径限本机固定磁盘、规范绝对路径、最多200个UTF16单位。不接受盘符根、相对/网络/设备路径、保留或歧义名称、数据目录包含关系、系统/系统级目录及任意祖先链接或目录联接。仍需当前用户写权限，不提权、不支持系统级安装。
- 原目录非空但无安装标识、受管文件手动修改、降级、运行中或文件锁冲突等保护保持。只替换/删除本程序受管文件，其他文件、账号任务和下载文件保留。
- 若安装登记/快捷方式失败会报告警告，不能假设新安装包能自动发现未登记位置；可显式指定原目录修复或从原目录运行卸载器。没有增加自动更新或数字签名。

目录选择使用[微软Shell.BrowseForFolder接口](https://learn.microsoft.com/en-us/windows/win32/shell/shell-browseforfolder)，在STA线程调用；仅从选择结果读取实际文件系统路径，再经过本地验证和确认。原生目录选择窗口的实际交互仍需用户复核，未对正式安装路径运行验证安装或卸载。

## 修改文件

- `internal/transfer/relay.go`、`relay_labels_test.go`：从任务保存类型生成公开历史标签及不依赖当前账号的回归。
- `frontend/src/RelayPanel.vue`、`tools/check-relay-ui.mjs`：历史网盘类型、同名区别、旧/未知类型和完整提示。
- `internal/installation/location.go`、`location_test.go`：安装位置资格、登记位置解析、安装/卸载目录绑定、路径与链接守卫及自选位置生命周期回归。
- `internal/installation/windows.go`、`install.go`：读取已登记位置及标识，拒绝所有重解析路径；沿用原受管文件/回滚逻辑。
- `tools/setup/main.go`、`folder.go`：首次位置选择、已安装位置恢复、显式目录参数、隔离边界、卸载父进程交接传原目录。
- `scripts/check-installer.ps1`：默认和中文空格自选位置安装/升级/锁拒绝/修复/卸载重装检查；自选模式额外拒绝测试根外与账号数据内目标。
- 六处当前版本/说明、开发计划及本版说明；生成桌面绑定同步展示字段，无新方法。

## 用户复测

1. 退出旧托盘后更新，打开中转页。已有记录应显示各自网盘类型与原账号名，原完成状态、目标路径、大小和缓存仍保留；无需重新传输。
2. 若当前已安装，再运行本版安装包，确认显示原目录并升级；无需为测试专门卸载或迁移正在使用的安装。
3. 有首次安装场景时，选择“自选父目录”，检查最终MultiPan子目录正确；取消应不安装。安装后从开始菜单打开，再次运行包应沿用自选目录。
4. 仅在确实需要卸载时，检查卸载指向自选原位置且账号/任务和其他文件保留；无需为了验收故意删除或改动程序文件。系统级安装、签名、自动更新及其他正式待办继续。
