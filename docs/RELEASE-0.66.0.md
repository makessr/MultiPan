## 协议依据与边界

实际读取作者源[BaiduPCS-Rust share_expire.rs](https://github.com/komorebiCarry/BaiduPCS-Rust/blob/main/backend/src/netdisk/share_expire.rs)：POST /share/mexpire，Cookie认证、不带bdstoken，表单share_id/expire_time/op_expire_days；有限期为Unix秒，永久两字段为-1。来源对3天有其抓包声明，永久仅网页脚本证据且未做真实请求验证。本机只做合成测试，不把作者声明当作本项目真实验收。

复用既有密封原记录句柄、加密写前意图、旧回执停用及未知防重放。原链接/名称/状态先读后写；内部ID始终字符串，不转浮点。写后重读同一原记录，有限期要求expiredType=0及绝对到期时间符合目标（120秒偏差），永久要求expiredType=1且expiredTime=0。返回不足或不一致保留未知；原结果检查不写。原码仅读取，不传pwd参数。来源变化、磁盘失败或待撤销阻止写。

同一未知原记录换期限仍返回原回执，重启只查。来源受限、自动转存等可能拒绝修改，不自动重试或重建；只有可核对的有效记录提供编辑入口。

夸克/123的原码和期限修改本轮未获得充分协议证据，不猜接口。123所检索SDK的更新仅涉及流量设置，不等同提取码/期限编辑。其他正式清单继续，不能据此声称服务商绝无修改能力。
