## 用户自行测试

1. 打开分享记录→云端分享·夸克，选择已有夸克测试账号：应出现官网已有分享，读取前后官网分享数量不增加。
2. 本页名称筛选、清空恢复；分享超过50条时翻页，最多每页50条。满50条的末页保守显示下一页，可能进入空页。
3. 选普通测试分享点读取原分享链接，核对原链接/提取码/期限与官网一致；复制完整信息及纯链接正确。已有无码/有码、永久/限期分享可分别测试，无需重建正式分享。
4. 已过期/失效分享或设置无法确认时应拒绝展示，并清掉此前链接，不自动创建/修改。
5. 已有多个夸克账号时切换：旧列表/链接清除；更新测试账号登录后旧异步结果不回填。其他网盘目前只保留原来的本机记录入口，不会误用夸克接口。

失败请提供版本、网盘、步骤和脱敏报错。不要提供Cookie、Token、加密状态或敏感分享链接。
