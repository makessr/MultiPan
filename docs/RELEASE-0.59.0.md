## 用户测试步骤（仅可丢弃测试分享）

1. 分享记录→云端分享·夸克，选普通测试分享点撤销，再点取消。预期官网原分享仍有效，无新增撤销回执。
2. 再次撤销并确认。预期出现撤销回执，官网原链接失效，网盘原文件仍存在；本机原创建记录不能复制旧链接。请勿用正式分享测试。
3. 如自然出现结果待确认，退出重开后回执应保留，检查原撤销结果不重复提交；查不到或网络失败不能直接认定成功，到官网核对即可，不反复点撤销。
4. 清理已确认回执并重启，旧本机创建记录不恢复链接或检查能力；未知回执不能清理，其他分享不受影响。
5. 测试账号更新登录后旧来源停止检查；云端列表暂时失败时本机撤销回执仍能显示。无须故意破坏网络或删除正式账号来覆盖测试。

失败提供版本、网盘、操作步骤及脱敏错误；不要发送Cookie、Token、state.enc或敏感分享链接。
