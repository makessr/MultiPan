## 功能

回收站选择百度，单个文件或文件夹可确认后还原到原位置。原路径、名称、类型或ID不完整时不提供有效还原句柄；夸克/123继续仅浏览。尚未实现批量还原、删除、永久删除或清空。

列表新增专用DPAPI密封还原句柄，绑定用途、账号、凭据来源、页码和原项目快照；公开展示ID不能直接用于写入。提交前重新读取原页，同ID/名称/类型/大小/路径全部匹配，并检查原目录可读、目标路径未占用；失败不提交。原目录不存在时不自动重建，恢复到其他位置尚未支持。

写前保存加密本机回执及提交检查点，最多1000条，同账号来源/文件ID去重。请求只发送一次；网络错误、响应缺失、异步未完成及重启均不能自动重发。“检查原还原结果”仅查正常文件列表；原ID、路径、名称、类型及可用文件大小一致才确认，不以回收站记录消失或HTTP成功代替。目录仅核对目录本身，不递归校验全部内部文件，内容请用户复测。

核对最多3次正常目录读取，间隔350ms，超时或状态不一致保留待确认。本机记录独立显示，待确认不可清理，已还原或未提交可清理；清理不操作云端。更换账号来源后不允许复用旧回执；有正在进行的上传/同账号变更时沿用现有互斥限制。提交前同名检查与实际服务端操作之间仍可能发生官网并发变动，原位置未匹配时只保留待确认，不自动重试或推断服务端重命名结果。
