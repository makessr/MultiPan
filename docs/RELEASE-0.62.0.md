## 用户测试步骤

1. 分享记录→云端分享→光鸭云盘。核对官网已有分享、名称/状态、分页和本页筛选；切换不残留其他网盘链接。
2. 用已有普通无码/有码分享读取原链接。核对链接、提取码和永久/剩余时间；可省略的原期限不应再误报，但状态/密码不能确认时必须拒绝展示。
3. 选可丢弃的正常测试分享，点撤销再取消，原链接仍有效。再次确认撤销，原链接失效，原文件保留；官网仍显示同一“已删除”记录也可确认。
4. 自然遇到待确认时重启仍有回执，只检查原结果，不重复提交；超出500项或网络失败不当成功。清理已确认回执并重启，旧创建记录不恢复链接。
5. 失效/未知状态不能执行撤销，更新测试账号登录后旧来源停止使用；原夸克/123/百度列表与撤销保持。

请勿用正式分享测试撤销。失败提供版本、网盘、步骤及脱敏报错；不要发Cookie、Token、state.enc或敏感分享链接。
