## 本次交付

- 夸克回收站支持文件/文件夹单项及最多50项混选还原，沿用统一确认、逐项结果、停止后续、首个未知/异常停后续、加密写前记录与重启只读核对。确认弹窗显示网盘和账号。
- 夸克回收站记录保留record_id、原文件fid、原父目录pdir_fid，严格区分用途。还原仅提交record_id；只有原父目录读回相同fid、名称、类型及文件大小才确认。API成功、记录消失或原位置有另一个同名文件均不能作为成功证明。
- 缺原fid、父目录、文件大小或可靠类型时保留浏览并禁还原。文件夹允许缺大小；目录内部内容需要用户核验。原目录无法完整读取、分页重复、同名冲突或回收站原记录变化时不提交。
- 百度、123、夸克批量还原增加整批只读预检查。重复记录/目标同名/账号来源不一致/已有本机还原记录或任一原记录、目标冲突，整批未提交；百度同名按不区分大小写检查。执行前仍逐项再核对，不能视作云端原子事务。
- 预检查期间也可停止，返回后不执行后续写操作；检查原结果不调用批量还原预检查或重新还原。最终回执保存失败时，已提交结果统一退为待确认，避免给出未可靠保存的成功状态。
- 夸克分页兼容metadata._total和data.total，矛盾总数拒绝。本次未接入夸克删除；公开客户端对删除action_type含义存在冲突，不猜测永久/回收站语义。

## 限制

夸克还原仅覆盖回收站返回完整原位元数据的项目，不猜路径、不选择替代目录、不覆盖同名项目。原目录ID已删除时服务端可能回退位置，只有在原目录核对到原fid才确认，其他情况到官网检查。
夸克每次原目录核对最多50页/5000项；批量预检查45秒，各百度/123原目录预检查使用5000项上限并复用同父目录列表。单项和核对沿用既有超时。预检查结束后其他客户端仍可修改云端；逐项再次检查不能消除服务端并发窗口。
未知记录不允许清理或重放；同一原记录已还原/未提交回执清理后可重新选择。未开始批次不跨重启自动执行。更换登录来源后旧记录只在原账号官网核对。升级后不要用旧版写同一state.enc，旧版可能丢弃新增元数据。
原有百度/123移入回收站保持；永久删除、清空回收站和其他盘复制等阶段未完成。搜索仍根目录及两级子目录，全部账号命中首个匹配后切换下一盘。

## 用户测试

1. 在夸克官网用可丢弃文件、带子目录的测试文件夹放入回收站；软件选择夸克刷新。原目录和类型完整的项目应可单项或混选还原，缺信息项目应保持禁用。
2. 先打开确认后取消，项目不变；再确认还原，核对软件结果、官网原目录和文件夹内容。若待确认，稍后点击检查原结果，不重复提交。
3. 三家任选：在某一待还原项目原位置新建同名测试项目，再混选多个还原。应整批检查失败，不先还原其他项；清理冲突后刷新重新选择。
4. 多项还原期间停止，当前请求结束后剩余不提交；退出重开，记录保留且不自动续还原。原结果核对不会再次发送还原请求，切换账号不串记录。
5. 反馈版本、网盘类型、原目录是否还在、逐项状态及脱敏错误提示即可；不发送Cookie、Token或state.enc。
