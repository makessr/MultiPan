## 协议证据与边界

- 夸克：作者项目的[接口实现说明](https://github.com/zhaocongqi/clouddrive-auto-save/blob/main/docs/quark_apis.md)记录GET /file/recycle/list及record_id/fid。沿用现有客户端的认证请求，分页_page/_size；总数取metadata._total（存在时）。未据此推断恢复或清空协议。
- 123：作者[网页抓包文档](https://github.com/crmmc/123pan-open/blob/main/doc/api_web.md)记录file/list/new的trashed开关；沿用项目已验证的签名/认证和Page分页，显式trashed=true，Next=-1结束，总数存在时辅助判断。
- 百度：作者[原实现](https://github.com/noanti/baidu-webdav/blob/master/api.py)的list_recycle_bin使用recycle/list与start/num/dir/order/desc。现有Cookie会话与固定官方地址认证；来源较旧，本项目真实接口验收待用户，不声称已经抓取用户响应。

本轮还核对了夸克/123原分享设置写入资料，未取得足以实现保留原链接编辑的可靠协议，不猜写接口或用重建代替。完整分享管理继续保留待办，先推进正式计划中的回收站读取。

## 用户复测

1. 退出旧版运行0.67.0，左侧回收站，分别选夸克、123、百度。与官网现有回收站记录核对名称、类型和大小。无需专门删除真实文件测试。
2. 超过100项时测试下一页/上一页/首页；筛选只作用于本页。记录是否缺失或重复，提供网盘、页码和错误文字即可，不需要原始响应或凭据。
3. 快速切换网盘或离开再回来，确认不会混入其他账号内容。空回收站应显示空记录，登录失效应显示错误。
4. 本版没有恢复/删除按钮，完整删除与恢复流程将在后续接入，计划第3项仍未完成。原分享和传输功能可正常继续使用。
