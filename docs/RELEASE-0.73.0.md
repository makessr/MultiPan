# MultiPan 0.73.0 复制记录与完整目录清单核对

2026-11-17 Windows x64。百度/诚通WebDAV/通用WebDAV复制流程扩展为加密记录、重启恢复、同源同目标防重放、单项/批量只读核对及完整目录元数据清单检查。真实账号待用户验收；不将此前未反馈功能记为真实验收通过。

## 新功能
- 复制前先保存本机记录；预检查和目录扫描完成后，再保存提交检查点与原清单，检查点保存失败不发送复制请求。记录与原有账号/任务状态一起通过DPAPI加密，不另存明文账号凭据。
- 同一账号来源、源项目和目标目录已有记录时不重新提交。最多1000条；已核对或未提交可清理，未知不可清理。清理只操作本机记录，保存失败回滚。
- 重启将已提交但未确认的操作恢复为待核对，未提交工作恢复为未提交；不自动续跑未开始队列、不重放写请求。切换账号来源后旧记录禁用检查和复用。
- 新增本机复制记录面板：名称/目标筛选、状态筛选、每页50条、刷新、检查原复制结果、核对全部待确认、停止后续核对及清理已完成。核对错误明确保留反馈，晚到账号结果丢弃。
- 文件夹复制前扫描相对路径、类型、文件大小及空目录；最多20层、500个子项目。源和目标都与提交前清单完全匹配才确认，缺项/多项/大小或类型不一致不报成功。文件不读取内容，目录清单不是内容哈希。
- 文件夹响应丢失时可通过完整元数据清单核对确认，WebDAV207仍立即保留待核对，可后续只读检查完整结果。原目录在复制后发生变化也会保留未知，不自动覆盖或合并。

## 边界与升级
复制服务仍仅百度/诚通WebDAV/通用WebDAV；其他网盘复制及回收站/删除协议继续待核对。本轮不标记第3/4阶段或跨盘第5阶段完成。目录扫描受服务调用60秒上下文限制；单个目录读取仍沿用现有分页实现，不声称固定最多网络请求次数。
0.72.0及更早复制不补录。新记录写入现有状态文件，升级后不要用旧版操作同一状态文件，避免旧版丢弃新字段；旧EXE/ZIP仅保留作档案。记录容量/目录扫描超限需拆分或清理已完成记录。结果是元数据清单一致，不保证文件内容逐字节一致；真实文件请自行打开/下载核验。外部客户端并发变化窗口仍存在。账号凭据来源变化会禁用旧记录核对，不能据此断言两个凭据是同一云端身份。

## 用户复测
1. 退出旧版运行0.73.0，用百度或WebDAV的可丢弃文件夹测试，内部包含文件、子目录和空目录。复制后核对源保留、目标层级、空目录与文件内容，本机记录应显示清单已核对。
2. 退出重开，新复制记录应保留。同源同目标再次复制应被记录拦截，不再写云端；若要再次复制，先核对并清理已完成本机记录，再处理同名目标。
3. 如出现待核对，使用单项检查或核对全部待确认；核对不发送新COPY/百度复制请求。未知记录不可清理。目录内容变化可能使记录保持待核对，请先到官网检查两端，不重复复制。
4. 测试名称/状态筛选、超过50条分页、清理已核对记录；清理不删除云端。更换账号来源后旧记录不允许检查。
5. 超过20层或500子项目应在提交前停止，显示未提交；拆小后再复制。反馈版本、网盘、步骤及脱敏错误，不提供Cookie/Token/state.enc。
