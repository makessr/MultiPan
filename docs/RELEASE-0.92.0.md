## 行为和边界

选择123或百度来源及另一DAV目标，读取来源后点击“复制此目录…”，确认后整棵预检。仍限制8层（所选根第1层）、20目录含根、20文件、256MiB单文件、全部记录1GiB/1000条和45秒预检。目标根同名拒绝，不合并。文件实际内容校验、部分失败停止、目录回执和父目录依赖保持。

123要求可靠目录/父ID、显式类型、文件大小和原内容MD5；百度还保存原目录fs_id。创建/上传前以及目标回读后重新核对祖先目录，路径相同但百度目录ID变化也不能继续旧任务。目录ID只定位目录，不证明文件内容不变。

专用严格读取器要求明确清单和分页完整性；缺失/null列表、重复或矛盾项目、提前结束及超限均明确“不完整”，不创建部分队列。123每目录最多5页/500项，百度最多2页、每页1000，第二页仍满则拒绝。普通浏览不改用这些更严格的上限。

缺少或格式异常的原内容版本使整棵预检拒绝；若百度返回的MD5虽格式正确但不代表原件，下载字节不符会停止，不猜测解码或关闭校验。此前可能已创建部分目标空目录，程序不自动删除或回滚。源始终保留，新源文件不追加，整个过程不是原子目录事务。

目录创建仍需明确受理凭据和准确回读，“目录创建已核对”不代表子文件已完成。已提交未知仅只读核对，无受理凭据不能凭同名目录确认；未提交项按父目录顺序手动继续，清理先子后父。预检中停止会等待读取返回，之后不入队。缓存保护、来源隔离和原123登录维护/恢复保持。

先从托盘退出旧版，不要让0.91及更早版本写同一状态。原透明PNG、图标备份和旧产物保留；用户限定的两级目录搜索/全账号首匹配切盘保持。
