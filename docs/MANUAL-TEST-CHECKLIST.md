# MultiPan 手动测试清单

适用于当前 1.0.0 正式工作区。建议先做必测项，再按你已有的网盘、系统和安装包补做平台差异。每个复选框对应一项可以单独回报的用例。真实账号测试由你执行。

## 准备测试数据

1. 准备至少两个不同网盘账号。有同名账号时保留原名，方便检查能否区分。
2. 在各盘建立专用测试目录。在两盘分别建「Windows2026 / 002实用工具」和「Windows2026 / 002 实用工具」，其中一盘可再建一个近似名。单独准备一棵至少四层的目录，用来确认搜索深度。
3. 准备小文件、中文及带空格的文件名、带子目录和空目录的本地文件夹、一个 500–700 MiB 测试文件，以及两个同名但内容不同的文件。蓝奏用白名单类型的小文件，单文件以 200 MB 为上限。
4. 测试前记录「设置与维护 → 传输设置」页底部的版本。分享、撤销、移入回收站和搬运只用测试数据。分享链接和提取码不放进问题截图。

## 1. 安装、界面和账号

- [ ] **A01 Windows 当前用户安装和图标（必测）**。双击对应架构的安装包。首次选择「是」走默认目录，打开开始菜单搜索 MultiPan。启动后看窗口标题栏、任务栏和托盘图标，确认三处为同一蓝色标识。若安装时选择了桌面快捷方式，也双击验证。缩放到 125% 或缩窄窗口，确认「多网盘上传」图标和文字作为一组居中，操作列的「…」可见且容易点击。
- [ ] **A02 自选目录、修复与卸载**。在测试机卸载后再次双击安装包，选择「否」并选一个空父目录，确认实际安装到该父目录下的 MultiPan 子目录。运行同版安装包验证修复。关闭客户端后打开 Windows「设置 → 应用 → 已安装的应用 → MultiPan → 卸载」，重新安装并打开。确认程序入口正确移除并能重建，测试账号、历史记录仍可读取。单独检查首次安装选择「取消」会直接退出。
- [ ] **A03 加账号、取消和重登（必测）**。在侧栏「我的网盘」点「+」，选网盘类型、填账号名称，点「登录…并保存」。先在官方登录窗口取消一次，确认未增账号，再完成登录并点击侧栏新账号，确认能看到自己的目录。点账号右侧铅笔，改显示名称并保存，确认原凭据继续可用。需要测试换登录时，重新点铅笔并勾「重新登录此账号」。WebDAV 和诚通 WebDAV 用地址、用户名和应用密码；有诚通 OpenAPI 授权时单独验证 Session 配置能保存并列目录。
- [ ] **A04 跨账号识别和状态保留（必测）**。进入「设置与维护 → 账号连接检查」。先点账号 A 的「检查此账号」，再检查 B，确认 A 的状态仍在。核对网盘名、账号、读取状态与本次尝试时间在同一行，时间紧邻状态。勾两行点「检查所选」，再试「停止检查」和「刷新状态」。点 B 的「更新登录 / 配置」，确认打开 B。
- [ ] **A05 重启与托盘**。关闭主窗口后，从托盘恢复窗口，检查进行中任务仍在。再通过托盘退出后重新启动，检查账号、已保存回执和队列仍能读取，需恢复的任务状态明确。

- [ ] **A06 诚通网盘（网页版，实验）**。在侧栏「我的网盘」点「+」，网盘类型选「诚通网盘（网页版登录，实验接入）」，填账号名称后点「登录…并保存」。在打开的官方登录窗口内完成登录（密码登录需过人机验证），确认窗口自动关闭并新增账号，账号名显示为网页端昵称。点侧栏该账号核对根目录能列出文件与文件夹；打开一个子目录，确认「上传」「新建文件夹」「重命名」「下载」和「更多操作 → 删除…」都可点；上传一个小文件、下载该文件并核对内容、新建一个文件夹、改名一次。删除时会弹确认框并提示不进回收站，确认后项目从列表消失，到网页端也应看不到。再在「设置与维护 → 账号连接检查」点该账号，确认显示已连接。另测：在官方网页端退出登录后回到程序刷新目录，应提示登录已失效并可重新登录；再次点「登录…并保存」，在已登录的网页端里重新走一遍登录流程，窗口也应在令牌出现后自动关闭，不停在「等待登录」；取消登录窗口不应新增账号。

## 2. 多网盘上传与目录匹配

- [ ] **U01 多盘上传主流程（必测）**。点侧栏蓝色「多网盘上传 → 选择文件」，选两个小文件，勾两个目标账号。分别点「选择目录」，进入测试目录后点「使用此目录」。点「开始上传」。全部项目通过预检时会自动创建任务；若出现预检对话框，核对账号、完整目标路径与保留项目，再点「上传保留的 … 项」。到「传输 → 上传任务」检查两盘进度，结束后分别点侧栏对应账号，确认文件在预期目录。
- [ ] **U02 同名及近似目录（必测）**。勾目标 A、B，先为 A 点「选择目录 → Windows2026 → 002实用工具 → 使用此目录」。查看 B 是否找到相同或近似名称。若 B 显示「候选目录」，点击所需的完整路径再预检。另测五种场景：B 无匹配、多个相似目录、某一级有多个候选但更深一层能唯一确定（应直接给出完整路径）、B 多套了一层目录（路径中应显示被跳过的那层）、只匹配到中间层（候选带「…」，点击后继续向下匹配）。再测已为 B 手动选过不同目录、切换 A 目录。点「开始上传」前核对两盘的最终目标路径。有歧义时应能辨认并选定目标。
- [ ] **U03 文件夹、拖放与重名（必测）**。同一页点「选择文件夹」，选带子目录的本地文件夹，再拖入一个文件和一个文件夹。在「本地项目」清单确认层级和目标，点「开始上传」。分别核对普通文件、子目录及空目录（以目标网盘支持为准）。对同一网盘再上传同名不同内容文件，按预检提示操作，并在网盘核实原文件未被误覆盖。另试蓝奏超过 200 MB 的文件，检查有明确拒绝或预检提示。
- [ ] **U04 任务停止与恢复**。上传一个较大文件后进「传输 → 上传任务」，在该行点「停止」，再点「继续 / 重试」。需要验证从头开始时使用「从头重新上传」。展开「文件夹与上传批次进度」，点「查看本组」和「查看本组失败项」，确认按批次及网盘分开。点「复制任务结果」核对显示的文件和目标。
- [ ] **U05 从目录页直接上传**。点侧栏一个网盘，进入测试目录，点「上传文件」或把本地文件拖到文件列表，确认窗口标题对应当前路径，再点「开始上传到此目录」。在上传任务、原目录两处核对落点。

## 3. 文件管理、下载和目录搜索

- [ ] **F01 浏览和操作列（必测）**。点侧栏账号，进入两级目录，通过面包屑、后退、前进回到正确路径。测试列表筛选、列头名称排序、Ctrl 多选、Shift 连选和 F5 刷新。点某行「…」再右键另一行，确认两处都能打开清晰的菜单，菜单操作对应正确项目。用 Ctrl+Shift+N 或「新建文件夹」创建一个测试目录，点「创建」；用 F2 或菜单「重命名」，再点「保存名称」。
- [ ] **F02 复制、移动与同名（必测）**。右键测试文件点「复制到…」，选择目标目录并按支持情况点「直接复制到此目录」「复制到独立子目录」或「经中转复制到此目录」。网盘侧确认副本和源件都存在。光鸭单文件直接复制后核对副本大小与内容，并确认目标没有多出临时子目录；目标已有同名项时应停止提交。再用另一批测试文件试「移动到… → 移动到此目录」，核对源和目标。对支持的网盘补测文件夹和文件混选、多文件夹批量移动，以及放入同名项后的行为。若出现「继续复制未提交项」，确认只带回未提交项。
- [ ] **F03 直接下载与结果**。右键测试文件点「下载」，选本地目录。分别测试单文件、多个文件、支持网盘的「下载文件夹」。进入「传输 → 下载结果」，核对成功、取消、失败与保存位置，点「打开保存文件夹」并比对文件内容。另做一次下载中途取消和「重试未完成」。
- [ ] **F04 下载队列、续传和历史（必测）**。勾文件点「加入下载队列」，或右键目录点「文件夹加入下载队列」。打开「传输 → 下载队列与历史」，点该行「暂停」，重启后点「继续」，核对进度、保存位置和结果。勾选结果试「复制所选结果」「导出所选报告」「打开保存文件夹」。本地冲突测试预先放一个同名不同内容文件，确认原文件没有被意外覆盖。
- [ ] **F05 目录搜索深度、全账号与停止（必测）**。点「目录搜索」，先选单账号。分别用文件名、文件夹名搜索，再勾「同时匹配路径」搜索 Windows2026 等路径片段并点「开始搜索」。确认会检查「根目录 / Windows2026 / 002实用工具」，不会进入其下一层目录；例如直接放在 002实用工具下的文件应可找到，放在它的子文件夹内的文件不应被扫描。再选「全部已接入账号（最多20个）」，确认第一盘命中后接着查第二盘，每盘至多返回首个匹配。点「打开所在目录」，核对账号和路径。另做一次「停止搜索」，确认已找到结果保留；遇到读取失败或上限时，展开「未完整扫描的原因」。

## 4. 分享管理

- [ ] **S01 单项、批量和链接（必测）**。在「文件管理」右键测试文件 →「分享链接」。在支持的平台选择提取码和有效期，再点「创建分享」。复制链接，在未登录或另一浏览器中访问，验证码与内容。接着混选两个文件或文件夹，从选择栏或右键打开「分享链接」，分别试「创建一个分享链接」和「分别创建分享链接」。蓝奏用「读取现有分享链接」或「读取所选分享」。
- [ ] **S02 本机分享回执和重开（必测）**。点「分享记录 → 本机操作记录」，按网盘、账号和操作筛选。分别点「复制完整信息」「只复制链接」「打开原文件目录」，确认账号、项目与剪贴板内容正确。对有「检查原结果」的记录点一次，确认只核对原结果。重启应用后再找同一条记录。
- [ ] **S03 新旧链接和撤销（必测）**。在支持的测试回执点「重新分享…」，检查原项目自动选中，调整设置后点「确认重新分享」。若服务商返回两条不同链接且界面提供入口，在新回执点「撤销旧链接…」，核对弹窗中的旧、新链接后点「确认撤销旧链接」。分别打开两条验证旧链接失效、新链接仍可用。若结果待确认，使用「检查旧链接撤销结果」。
- [ ] **S04 云端分享列表和支持的编辑（必测）**。点「分享记录 → 云端分享」，选账号并点「刷新云端列表」。分别试「读取原分享链接」「批量读取所选」，也可将两页的测试项加入「跨页分享清单」。123 普通分享、百度测试「编辑分享设置」修改期限，光鸭测试允许的提取码与期限编辑。夸克可试「查看受限文件」。在官网复核修改值。选测试链接点「撤销分享」或「批量撤销所选」，先做一次「取消」确认无变化，再实际确认并读回。
- [ ] **S05 123 付费分享（仅有测试权限时）**。从「文件管理 → 分享链接」切换付费模式，核对测试金额，点「提交付费分享审核」。在「分享记录 → 本机操作记录」按创建 123 付费分享筛选，点「到官网查看审核」。在「云端分享」切换付费视图，验证独立列表和已开放的下载设置编辑。全过程无需购买链接。
- [ ] **S06 蓝奏分享目录**。点「分享记录 → 蓝奏目录分享 → 选择目录」，进入测试目录后点「读取分享链接」。点「搜索蓝奏项目」找另一个已知测试项并加入「跨目录候选清单」。进入清单后点「读取清单链接」，逐项核对来源与实际链接。用专用测试链接点「修改提取码」或「批量修改提取码…」，在未登录浏览器核对修改结果。若当前版本的区域标题显示在蓝奏账号下，先切换到对应账号。

## 5. 网盘中转、核对与账号维护

- [ ] **T01 中转一个大文件（必测）**。点「传输 → 网盘中转」。在「来源账号」选 123、在「目标账号」选百度。两边分别点「选择目录」，来源点「读取文件」，勾一个 500–700 MiB 样本。点「创建中转复制队列」，核对先读取源文件到本机缓存、再上传、最后核对目标。结束后检查记录中的网盘、账号、目标路径和内容核对状态，确认源文件仍在。限速时记录该阶段持续时间和速度。
- [ ] **T02 目录中转与失败恢复（必测）**。选来源及目标后，点「读取文件」，对一个有子目录的样本点「复制此目录… → 确认预检并创建目录队列」。在目标盘核对目录层级及文件数量。再试预先存在同名目标、选择不支持的空文件，以及「停止全部中转」后重开页面。对于仍待确认的记录，先点「只读核对目标」，留意是否保留已完成项目及本机记录。夸克、光鸭分别做来源和目标各一次。勾选「读取网盘原件用于核对」测试非本机上传的文件。有大样本时，验证超过 4 GiB 且不超过 8 GiB 的单文件可入队，单批或目录超过 16 GiB 时显示限制。
- [ ] **T03 已有搬运的兼容回归（可选，有删源动作）**。只用可丢弃专用文件。先完成 T01 或 T02；对支持来源且内容已核对的记录，点「完成搬运并移入回收站…」或「搬运目录内文件…」。先点「取消并保留源文件」验证无变化。若仍需验收写入，再重新打开确认，点「确认开始搬运核对」。检查目标副本可用，源侧只处理确认清单内项目，目录和未选项目保留。结果待确认时点「只读核对搬运结果」。回收站页、永久删除与整站清空已停止开发，本清单无需主动验证。
- [ ] **T04 待核对中心**。若前面自然产生待确认回执，打开「设置与维护 → 待核对中心 → 刷新本机回执」。按操作、账号筛选。点「只读核对这一项」或勾两项点「只读核对所选」，再试「停止后续核对」。点「前往原模块」，确认落在该账号及回执。核对勾选框与其他列表尺寸相近。没有待确认回执时只验空状态，无需人为制造失败。
- [ ] **T05 登录失效入口**。登录自动续期已按用户决定移除，侧栏不再有「123 登录维护」。请确认账号登录失效时仍能从账号或连接检查页进入原有的更新登录流程，保存后回到文件管理刷新目录可正常浏览。
- [ ] **T06 传输设置持久化**。点「设置与维护 → 传输设置」，修改一个上传并发或速度设置，点「保存设置」，重启确认仍显示保存值。上传或下载一个测试文件观察效果，再恢复之前的值。

## 6. 平台预览与发布后验收

- [ ] **P01 Windows x64、ARM64 预览包**。在对应架构真机用各自安装包执行 A01 至 A03，和 U01、F03 各一次。ARM64 上另核对 Windows「设置 → 系统 → 系统信息」的系统类型，以区分原生 ARM64 与仿真测试。
- [ ] **P02 Linux amd64 与 arm64**。在对应架构、已解锁桌面钥匙环的 Linux 环境，用应用商店的本地包安装功能或 `sudo apt install ./对应架构的包.deb` 安装。打开应用菜单搜索 MultiPan。执行 A03（展开「手动导入登录信息」或添加 WebDAV）、U01 和 F03 的最短路径。退出再打开，确认仍能列目录。安装命令及适用系统见[桌面版发布说明](DESKTOP-DISTRIBUTION.md)。
- [ ] **P03 macOS Apple Silicon 与 Intel**。先在苹果菜单「关于本机」核对芯片，再下载对应 ZIP 和 SHA-256。确认摘要后解压，将 MultiPan 拖到「应用程序」，双击打开，记录首次启动是否出现 Gatekeeper 提示。按当前未公证预览策略记录实际结果；能启动时用手动导入或 WebDAV 执行 A03、U01、F03，并退出重开验证钥匙串读取。
- [ ] **P04 Windows 正式在线更新（当前暂停）**。在较旧受支持版本点「设置与维护 → 传输设置」，滑到「应用更新」。点「检查更新 → 下载已核对的安装包 → 打开更新安装器…」，核对安装器版本、更新后应用版本及原账号和记录。另做一次下载时取消；镜像异常时看能否继续下载同一版本。当前 Windows 通过 GitHub Releases 手动下载安装。若以后恢复正式在线更新，再执行此项。
- [ ] **P05 正式 APT 源（等待发布地址和公钥）**。正式提供 HTTPS 地址和公钥后，按[桌面版发布说明](DESKTOP-DISTRIBUTION.md)配置来源。分别在 amd64、arm64 运行 `sudo apt update` 和 `sudo apt install multipan`，从应用菜单启动。下一次发行后从原源执行更新并核对版本、架构和本机数据。
- [ ] **P06 Windows 全用户 MSI（x64、ARM64 各一轮）**。在测试虚拟机核对 `.msi.sha256` 后双击对应 MSI。首次到 UAC 时点「否」，确认「已安装的应用」没有新增条目。重跑并允许提权，在功能页先保留公共桌面默认关闭，完成安装。打开「设置 → 应用 → 已安装的应用」，确认有「MultiPan（所有用户）」。切换到普通 Windows 用户，从开始菜单点「MultiPan（所有用户）」，确认能启动、公共桌面没有快捷方式、账号配置属于当前用户。回到管理员会话，运行同一 MSI 进入维护并启用「公共桌面快捷方式」，再用普通用户核对桌面入口。用后续版本的同架构 MSI 验证升级。安装完成后在同一目录运行 `.\MultiPan-setup.exe --action install --inspect-machine-integration --silent`，确认 `installer` 为 `msi`、`registration.status` 为 `managed-by-installer`、两个快捷方式为 `matches`；未安装全用户版本时应为 `installer: none`。最后从「已安装的应用」卸载，确认公共快捷方式和程序文件被移除，两个用户各自的配置记录仍可读取。另在干净虚拟机预置同名安装目录或公共链接，验证首次安装拒绝覆盖。

- [ ] **P07 Windows 开发诊断（可选）**。在资源管理器打开开发产物所在目录，在地址栏输入 `powershell` 并回车，然后运行 `.\multipan-machine-acl-setup-check.exe --inspect-machine-integration --silent`。在本轮测试机上应看到 `directorySecurity.status` 为 `checked`，另三项为 `missing`；其他电脑记录实际值。命令返回 JSON 即结束，期间无需安装或确认提权。

尚未开放的已有分享原位编辑项、蓝奏完整发布列表与独立撤销、各网盘原生复制缺口，以及诚通公开分享，等开发计划标记可验收再补步骤。登录自动续期与跨网盘扩源/删源搬运已按用户决定停止推进，不再列入验收。
