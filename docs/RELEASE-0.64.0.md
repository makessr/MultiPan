# MultiPan 0.64.0 光鸭原分享设置编辑

日期：2026-11-17，Windows x64。用户已反馈0.63.3修正“可以了”，本轮继续正式计划第2阶段；本版新编辑能力真实账号待用户测试。

## 使用入口与范围

分享记录 → 云端分享 → 选择光鸭 → 有效记录的“编辑分享设置”。打开先读取原链接、提取码及当前期限，不发送修改。可设置/取消4位字母数字提取码，重新选择1/7/30天或永久；必须明确选择目标期限，避免只想改码时默认延长。保存会影响原分享访问方式，原链接保留，不创建替代链接。期限从本次修改起计算。

本版只接入光鸭原分享编辑；蓝奏已有文件级设码保留，夸克/123/百度等仍需独立核对协议。不能把本版视为所有网盘设置编辑完成。没有代用户操作真实分享。

## 实现与核对

协议证据沿用已保存的光鸭官网公开index.572308ad5c.js：有效记录的编辑菜单向/userres/v1/update_share发送原行内部id及编辑表单数据。原行有独立公开shareId，不能拿公开标识替代内部id。只读取这份既有字节，不运行外部代码，不把公开前端当成官方稳定接口保证。

保存前验证来源绑定、原页精确内部ID及原始JSON类型、公开ID、标题/URL和正常状态；原数据不完整或目标变化不写。提取码与期限为用户明确输入，下载方式、流量、转存次数、口令等已返回字段按原值带回；缺省downloadType/maxRestoreCount按官网表单规则为0。未提供独立高级设置编辑功能，需用户核对官网原高级设置保持符合预期。

复用本机加密分享回执，新增settings操作与密封原记录句柄；写前保存意图，并将同一原分享的旧本机创建/编辑回执标记为过时，不再复制旧码。无论更新响应是否有data，都只按原记录的访问模式、实际码及目标期限判定结果。永久要求leftTime=-1，有限期限核对剩余时间与本次意图时间（允许120秒偏差），不只看原申请天数。返回不一致保留未知。

同一原记录已有未知编辑时，更换密码/期限不会重发；同一已成功意图再次调用只核对。重启在本机分享记录检查原结果，无自动提交。账号登录来源变化或已进入撤销流程拒绝修改。旧过时回执跨重启保持不可用，避免清理/重启后旧码复活。

新增一个桌面方法，60方法/33模型；ShareInput增加可选私有句柄、加密状态增加可选Superseded标记，旧记录兼容。保留原分享创建/检查接口及其他功能。

## 用户测试清单

请仅使用可公开、可丢弃的测试分享，编辑会影响原链接。

1. 光鸭官网准备一条测试分享，记下原链接及下载/流量等高级设置。进入上述编辑入口，先关闭，官网内容与设置应不变。
2. 修改提取码，明确选择7天并保存。应得到原链接，打开后新码可用，官网显示新码和新期限；原文件保留且不新增一条替代分享。
3. 再次编辑取消提取码并选择永久，原链接应无需提取码即可访问，官网期限永久。重新设置提取码也应可用。核对高级设置没有非预期变化。
4. 重启到分享记录检查本次设置回执，读取不会新增分享或再次延长期限；旧本机创建/编辑回执应停止复制旧码。
5. 若自然出现待确认，先检查原结果，不重新提交；关闭再开、换码也应返回原未知回执，不重发更新。无需主动断网制造不确定写操作。
6. 回归光鸭原链接读取/撤销、其他网盘分享、百度上版原记录检查。仍报错请提供版本、操作阶段和脱敏错误文本，不需凭据、状态文件或真实链接。
