## 原因与修正

实际核对已保存光鸭官网公开前端index.572308ad5c.js，表单枚举明确为“无提取码=0、随机生成=1、自定义=2”。此前原分享读取代码只接受0和2，遗漏了合法随机模式1；因此这种原分享无法读取，编辑窗口打开前的只读校验也被阻止。

新增共用访问设置核对：无提取码模式仅接受空码或官网“-”占位；随机/自定义两种密码模式都必须返回实际4位字母数字码。needCode开关有返回时必须与实际模式一致。缺模式、未知模式、缺码/错误码及开关矛盾仍拒绝，不根据空码猜成公开分享。错误增加无敏感信息的mode/reason分类，便于后续区分。

原链接读取与设置结果核对复用该规则；原创建分享的密码模式核对也兼容随机模式，但实际码仍须符合申请，不放松原ID、URL、标题、状态、期限和未知防重放要求。API/公共模型仍60方法/33模型，不新增云端写接口或修改已有分享。

截图不能单独证明实际响应是mode=1还是缺失模式；本次以官网源码和可复现合成检查修复明确遗漏。若仍失败，新mode/reason可帮助定位真实的字段缺失或矛盾。
