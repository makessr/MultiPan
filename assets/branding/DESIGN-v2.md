## 完整生成提示词

Use case: logo-brand. Create one original app icon for MultiPan, a Windows multi-cloud storage file manager that uploads one file to multiple drives. Inspired by the visual simplicity, friendly rounded silhouettes, generous scale and instantly legible paired-symbol composition of the WeChat app icon. Adapt that design language into TWO overlapping soft white cloud-storage silhouettes, one slightly upper left behind, one slightly lower right in front. They should read as cloud drives, not speech bubbles: no tails, no eyes, no dots. Bold, very simple, elegant cloud contours with only a few broad rounded lobes and flat rounded bottoms; front cloud pure white, rear cloud very pale ice blue; use a clean blue negative-space separation between the pair. Center this large paired mark inside a blue rounded square tile. Background is the actual MultiPan theme cobalt blue #2863D7 with only an extremely subtle lighter top tonal shift, never green. Flat vector-like graphic, precise smooth silhouette, balanced optical weight, recognizable at 24 pixels. Tile occupies 90% of a square canvas, symbol approximately 70% of tile width. Genuine transparent exterior around the rounded tile and in outer corners. ONE standalone icon only. No lettering, no M glyph, no arrows, no small details, no outlines, no bevels, no 3D, no gloss, no external shadows, no mockup, no contact sheet, no watermark.
