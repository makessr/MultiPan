# MultiPan 图标设计 v1

2026-11-17；用户要求生成软件图标 logo。使用内置 image_gen（非 CLI），未替换现有构建图标，保留为独立设计稿。

最终文件：multipan-icon-concept-v1.png，1254×1254 PNG，透明外部。钴蓝圆角底、白色折叠文件组成 M，青色连接表达多网盘汇聚。原生生成稿，非矢量或 ICO；尺寸转换及软件接入应由后续图标资产流程处理。已目视检查；顶部透明边距抽样最大 alpha 为 1/255，角像素 alpha 为0，未声称透明区全零。

生成提示词

Use case: logo-brand. Asset type: final Windows desktop application icon for MultiPan, a local multi-cloud-drive file manager. Create ONE polished, original, production-quality icon, not a presentation board. Square 1:1 composition. A cobalt blue rounded-square tile with genuinely transparent exterior corners and margins. Inside, a bold custom white M-shaped symbol built from two broad folded file ribbons that meet in a central valley, with a restrained cyan lower connector suggesting multiple storage paths unified into one. The M must feel purpose-drawn, geometric, balanced and strongly recognizable at 24–48 pixels, not a typed font glyph. Maintain generous clear negative space, consistent optical weight, precise curves and crisp edges. Palette: rich cobalt #2863D7, deeper blue #1646B7, white #FFFFFF, small cyan #45D9ED accent. Flat vector-like graphic with only a very subtle blue tonal transition on the tile; no metallic or glass effects. Tile occupies about 88 percent of canvas; centered symbol occupies roughly 65 percent of tile. No wordmark, no small text, no slogan, no cloud clipart, no network-node dots, no upload arrows, no surrounding devices, no drop shadow outside tile, no mockup, no extra variants, no decorative background. Deliver a single clean standalone app icon with transparency, suitable as the source master for Windows icons.

清理编辑提示词

Use case: precise-object-edit, logo-brand production cleanup. Edit the attached MultiPan application icon. Preserve the exact blue rounded-square tile, the white folded-file M mark, cyan connector, geometry, proportions, colors and composition. Make ONE targeted change: clean the alpha silhouette completely. Remove every stray blue fleck, noise pixel, accidental mark, and fringe outside the rounded-square tile, especially above and below it. All pixels outside the single clean rounded-square contour must be fully transparent. The outer edge must be smooth, precise, antialiased and free of halos. Preserve transparency and generous transparent margins. No new objects, no text, no background, no added shadow. Deliver the clean standalone app icon.
